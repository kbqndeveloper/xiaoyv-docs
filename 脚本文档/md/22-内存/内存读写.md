# 内存读写

按地址读写数值、字符串和字节数组，也可查询页面状态与权限。

## 数据类型

| 常用常量 | 含义 | size 参数 |
|---|---|---|
| `mem.i8` / `i16` / `i32` / `i64` | 有符号 8/16/32/64 位整数 | 不使用 |
| `mem.ui8` / `ui16` / `ui32` / `ui64` | 无符号 8/16/32/64 位整数 | 不使用 |
| `mem.f32` / `f64` | float / double | 不使用 |
| `mem.str` | 字符串，读取到首个零字节 | 最大读取字节数，默认 64 |
| `mem.bin` | 字节数组，例如 {0, 255} | 字节数，默认 16 |
| `mem.utf16` | 以 UTF-8 字符串读写 UTF-16LE 内容 | 读取码元数，默认 16 |

**方法名称：** 按地址读写内存（Android）。

**语法：** 见下方方法表。

**参数说明：** `address` 为目标地址；`kind` 使用实例上的类型常量。数值写入用 number，字符串用 string，bin 用 0..255 的整数字节数组。

| 方法 | 参数 | 返回值 | 说明 |
|---|---|---|---|
| `mem:read_memory(address: integer, kind: string, size?: integer)` | address：目标地址；kind：类型常量；size：str 默认 64 字节、bin 默认 16 字节、utf16 默认 16 码元 | value: number\|string\|integer[] 或 nil, error: string | 按类型读取；size 仅用于字符串、字节数组和 UTF-16 |
| `mem:write_memory(address: integer, value: number\|string\|integer[], kind: string)` | address：目标地址；value：数值、字符串或字节数组；kind：类型常量 | true 或 nil, error: string | 按类型写入 |
| `mem:isMemory(address: integer, size: integer)` | address：起始地址；size：字节数，建议 >0 | present: boolean | 按 pagemap 检查页面 present 状态 |
| `mem:getMemoryPermission(address: integer)` | address：目标地址 | permissions: string\|nil, ok: boolean | 查询地址所在映射的权限 |
| `mem:setMemoryPermission(address: integer, permissions: string)` | address：目标地址；permissions：至少三个字符，如 rw- | ok: boolean | 修改地址所在一页的权限，使用 r/w/x 前三位 |

| 返回值 | 说明 |
|---|---|
| value | 数值类型返回数字，str/utf16 返回字符串，bin 返回字节数组；失败返回 nil, error |
| true | 写入成功；写入失败返回 nil, error |
| permissions, ok | 例如 "rw-p", true；未找到或查询失败为 nil, false |
| present | 页面 present 状态，不能据此判断可写或地址中存在有效对象 |

## 示例

```lua
-- address 是已确认的目标地址，以下按 int32 读写。
local before, err = mem:read_memory(address, mem.i32)
assert(before ~= nil, err)
local ok, writeError = mem:write_memory(address, 100, mem.i32)
assert(ok, writeError)
local after, readError = mem:read_memory(address, mem.i32)
assert(after ~= nil, readError)
print("修改前后", before, after)

-- textAddress 和 bytesAddress 分别指向字符串和字节区。
local text, textError = mem:read_memory(textAddress, mem.str, 64)
assert(text ~= nil, textError)
local bytes, bytesError = mem:read_memory(bytesAddress, mem.bin, 8)
assert(bytes, bytesError)
print(text, table.concat(bytes, ", "))
```

## 使用说明

- str 写入自动添加一个零字节；utf16 不补终止符；bin 写入全部数组字节。均不自动扩容。
- 窄整数写入按宽度截断；`char` 的符号性随宿主 ABI，明确的有符号单字节用 i8。
- `isMemory` 只检查 pagemap 的 present 位，建议 size>0，不保证可读写或存在有效对象。
- `setMemoryPermission` 接收至少三个字符，例如 `"rw-"`，只读取前三位 r/w/x，通过目标 mprotect 修改地址所在的一页。
