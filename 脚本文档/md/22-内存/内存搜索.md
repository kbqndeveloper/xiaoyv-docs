# 内存搜索

按数值和区域搜索地址；先限定范围，再增加条件。

**方法名称：** 按条件搜索内存（Android）。

**语法：** 见下方方法表。

**参数说明：** `params` 是搜索配置表，head 必填，types/rangs 至少提供一个；字段定义见本页下方。

| 方法 | 参数 | 返回值 | 说明 |
|---|---|---|---|
| `mem:search_memory(params: XiaoYvMemSearch（table）)` | params：搜索配置，见下方字段表 | addresses: integer[], message: string? 或 nil, error: string | 按条件搜索，返回的地址已排序 |

| 返回值 | 说明 |
|---|---|
| addresses | 按地址排序的整数数组 |
| {}, message | 无命中，message 为“没有找到结果”；空表在 Lua 中为真，需检查 #hits |
| nil, error | 请求被拒绝或搜索失败；缺少必要配置等参数问题会直接抛错 |

**详细说明：**

## 示例

```lua
-- 在已知范围 [startAddress, endAddress) 查找 int32=100。
local hits, message = mem:search_memory({
    rangs = {{Star = startAddress, End = endAddress}},
    head = {type = mem.i32, data = 100},
    max = 20,
})
assert(hits, message)
if #hits == 0 then print(message) end
for _, address in ipairs(hits) do print(string.format("0x%X", address)) end

-- 按区域搜索，并要求命中地址 +4 处的 float >=1.5。
local matches, err = mem:search_memory({
    types = {mem.range.JH, mem.range.A},
    head = {type = mem.i32, data = 100},
    data = {{offset = 4, type = mem.f32, lv = 1.5}},
    max = 20,
})
assert(matches, err)
```

## 使用说明

- 保留拼写与大小写：`rangs`、`Star`、`End`、`Remove`。types/rangs 至少一个，二者取并集。
- 主条件用 head；data 中的条件均相对主命中地址，且必须全部满足。比较键 data=等于、lv=大于等于、hv=小于等于；同一条件按 lv、hv、data 优先级只取一个。组合上下界时可追加 offset=0 的条件。
- max=0 表示不限；配额在去重前占用，重叠范围可能导致结果少于 max。返回地址已排序，但不保证是最小的前 N 个。
- Remove 排除范围沿用 `Star-1`、`End+1` 切分规则；与 rangs 的半开区间不同。
- 字符串按字节精确匹配，最多 64 字节，不支持通配符；bin/utf16 不可用于搜索。浮点相等采用绝对误差 <0.000001，数值需有限。
- nop=true 按 pagemap present 位过滤，无法打开 pagemap 时继续用原范围。

## 搜索参数

区域常量见[常量附录](常量附录.md)。

**类型：** `XiaoYvMemSearch`（table）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| pid | integer | 否 | 默认当前目标，仅覆盖本次搜索 |
| head | XiaoYvMemCondition（table） | 是 | 主比较条件 |
| types | string[] | 否 | 区域分类，与 rangs 至少提供一项 |
| rangs | XiaoYvMemRange（table）[] | 否 | 自定义扫描范围，保留原拼写 |
| data | XiaoYvMemCondition（table）[] | 否 | 相对主命中的附加条件 |
| Remove | XiaoYvMemRange（table）[] | 否 | 排除范围，首字母大写 |
| max | integer | 否 | 0..2147483647，默认 0 不限 |
| nop | boolean | 否 | 默认 false；按 pagemap present 过滤 |

**类型：** `XiaoYvMemCondition`（table）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| type | string | 是 | 类型常量，例如 mem.i32 |
| data | number\|string | 否 | 相等值，与 lv/hv 至少提供一个 |
| lv | number | 否 | 大于等于的比较值 |
| hv | number | 否 | 小于等于的比较值 |
| offset | integer | 否 | 附加条件必须给出，相对 head 的 int32 字节偏移；head 不需要 |

**类型：** `XiaoYvMemRange`（table）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| Star | integer | 是 | 起点，保留原拼写 |
| End | integer | 是 | 终点 |
