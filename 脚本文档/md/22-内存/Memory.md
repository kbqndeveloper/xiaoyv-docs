# 入门与使用说明

小鱼 Android 内置内存模块，无需提供 SO 路径。先创建对象并选择目标，再按功能页调用。

**方法名称：** 创建内存对象（Android）。

**语法：** 见下方方法表。

**参数说明：** 构造函数不需要参数，也不需要 SO 路径。

| 方法 | 参数 | 返回值 | 说明 |
|---|---|---|---|
| `Memory:new()` | 无 | mem: XiaoYvMemory（table） | 创建对象，初始 pid=-1 |

| 返回值 | 说明 |
|---|---|
| mem | 新的内存对象，初始 pid=-1，尚未选择目标 |

**详细说明：**

## 示例

```lua
local Memory = require("mem")
local mem = Memory:new()
local _, pid = mem:get_pid("com.example.app")
print("当前 PID", pid, "位数", mem.arch)

local rows, err = mem:getModuleInfo("libexample.so")
assert(rows, err)
for _, row in ipairs(rows) do
    print(string.format("0x%X", row.start), row.size, row.perms, row.path)
end
```

## 使用说明

### 环境与架构

在小鱼中启用 Root 模式，并启动目标应用。ARM64 是主要支持和测试目标；x86_64 提供基础及远程功能。32 位引擎的远程调用、远程分配、SO 注入和权限修改不可用。K 仅提供 ARM64 客户端，需外部驱动配合，详见[内存读取方式](内存读取方式.md)。

### 各页共用的约定

- 示例中的 `mem` 是已选好目标的对象；`address`、`base`、`instance` 等是业务代码取得的真实目标地址，包名和偏移需替换。
- 每个对象分别保存 PID 和位数；进程重启或 exec 后重新选择目标并获取地址。读取方式由同一脚本执行进程内的对象和线程共享。
- 地址及 64 位整数使用 Lua 整数，不经过浮点转换。uint64 最高位为 1 时显示为负整数，位模式仍完整。
- 返回值以命令表为准：nil、false、0 或错误字符串各有含义；非法参数可能抛错。需要捕获抛错时使用 `pcall`。
- 返回的 Lua 字符串和表自动管理；主动申请的远程映射需自行释放，主动暂停的进程需自行恢复。
- 读写不会暂停目标，也不保证多次操作是原子的；写入后续步骤失败不会自动回滚。
