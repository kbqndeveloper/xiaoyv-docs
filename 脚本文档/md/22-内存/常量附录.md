# 对象字段与常量附录

查常用用法时先看[内存读写](内存读写.md)、[内存搜索](内存搜索.md)和[内存读取方式](内存读取方式.md)。本页集中列出完整字段和值，供查阅和代码提示使用。

常量属于 new 创建的实例，例如 `mem.i32`、`mem.PROT_READ`，不要写成 `Memory.i32`。`mem.pid`、`mem.arch` 通过 get_pid/set_pid 更新；range 表保存区域字符串。

系统标志使用 `|` 按位组合，例如 `mem.PROT_READ | mem.PROT_WRITE`。保留的 MADV、MS、MREMAP 等常量不表示模块提供了同名方法，也不保证设备内核支持这些标志。

## 搜索区域

区域按映射路径、权限和偏移推断，并非系统提供的绝对分类。推荐统一用 `mem.range.名称`；简写 `mem.S` 被读取方式占用，搜索栈必须用 `mem.range.S`。

**类型：** `XiaoYvMemRegions`（table）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| J | string | 是 | 区域 `j`：其他 Dalvik 区域 |
| PS | string | 是 | 区域 `ps`：路径含 ppsspp_ram，不泛指共享内存 |
| XA | string | 是 | 区域 `xa`：匿名或应用目录中的可执行映射 |
| CD | string | 是 | 区域 `cd`：应用目录的 SO 非执行映射 |
| BAD | string | 是 | 区域 `bad`：xlog、系统字体、dmabuf 等映射 |
| AS | string | 是 | 区域 `as`：ashmem，排除 memoryheapbase |
| CB | string | 是 | 区域 `cb`：系统库非执行映射及关联 BSS |
| JH | string | 是 | 区域 `jh`：Dalvik heap/alloc/main/large/free 等堆区 |
| OTHER | string | 是 | 区域 `other`：未归入其他类别 |
| S | string | 是 | 区域 `s`：stack 栈映射 |
| VIDEO | string | 是 | 区域 `video`：mali、kgsl、dri 等图形映射 |
| A | string | 是 | 区域 `a`：无路径、可读写、offset=0 的非执行映射 |
| XS | string | 是 | 区域 `xs`：其余可执行映射 |
| CA | string | 是 | 区域 `ca`：libc_malloc、匿名线程栈、malloc、/dev/zero 等 |
| CH | string | 是 | 区域 `ch`：heap 堆映射 |
| ALL | string | 是 | 区域 `all`：全部 maps 范围，实际读取仍可能失败 |
