# 辅助功能

提供编码转换、文件 MD5、简单 HTTP 和应用 ABI 操作；无需先选择 PID。

**方法名称：** 编码、文件和应用辅助功能（Android）。

**语法：** 见下方方法表。

**参数说明：** text 为 UTF-8 字符串，bytes 为偶数字节的 UTF-16LE 字符串。path 为文件路径，url 为明文 HTTP 地址，package 为应用包名。

| 方法 | 参数 | 返回值 | 说明 |
|---|---|---|---|
| `mem:utf8_to_utf16(text: string)` | text：UTF-8 文本 | bytes: string | 转换为 UTF-16LE 字节，不附加终止符，遇首个零码元截断 |
| `mem:utf16_to_utf8(bytes: string)` | bytes：偶数字节的 UTF-16LE 字符串 | text: string | 从偶数字节的 UTF-16LE 转成 UTF-8，遇首个零字节截断结果 |
| `mem:file_md5(path: string)` | path：本地文件路径 | hex: string\|nil, status: integer | 计算文件 MD5，返回 32 位小写十六进制文本，成功状态为 0 |
| `mem:http_get(url: string)` | url：明文 HTTP 地址 | body: string\|nil, status: integer | 原内存库的简单 HTTP GET，成功状态为 0 |
| `mem:http_download(url: string, path: string)` | url：明文 HTTP 地址；path：保存路径 | status: integer | 原内存库的简单下载，成功为 0 |
| `mem:getAbi(package: string)` | package：应用包名 | abi: string\|nil, error: string? | 查询包的 primaryCpuAbi |
| `mem:ConvertAbi(package: string, abi: string)` | package：应用包名；abi：mem.arm/arm64/x86/x64 | output: string, ok: boolean 或 nil, error: string | 从包路径执行 pm install -r --abi，结果取决于包和系统 |

| 返回值 | 说明 |
|---|---|
| bytes / text | 转换后的 Lua 字符串；不包含额外终止符 |
| hex, status | 32 位小写十六进制 MD5；status=0 成功，失败为 nil 和非零状态 |
| body, status / status | HTTP 成功状态为 0，失败为非零；body 为字节字符串或 nil |
| abi, error | getAbi 返回 primaryCpuAbi 文本；未解析到时可为 nil；系统也可能给出字面量 "null" |
| output, ok | ConvertAbi 的命令输出及成功标志；无法执行或未找到 APK 时返回 nil, error |

**详细说明：**

## 示例

```lua
local mem = require("mem"):new()
local bytes = mem:utf8_to_utf16("小鱼")
print(#bytes, mem:utf16_to_utf8(bytes))

local hex, status = mem:file_md5("/sdcard/example.bin")
assert(status == 0 and hex ~= nil, "MD5 计算失败")
print(hex)

local body, httpStatus = mem:http_get("http://example.com/")
assert(httpStatus == 0 and body ~= nil, "HTTP 读取失败")
print(body)

local abi, err = mem:getAbi("com.example.app")
assert(abi, err or "未查询到 ABI")
print(abi)
```

## 使用说明

- UTF 转换会在输出首个零码元/零字节处截断；非法编码可能产生部分输出，不返回编码错误，不适合保留嵌入 NUL 的任意二进制数据。
- HTTP 仅支持明文，不支持 HTTPS、重定向、chunked 解码或完整状态判断；status=0 不代表 2xx。常规网络请求使用小鱼[网络接口](../16-网络与通信/概述.md)。
- `getAbi` 返回 primaryCpuAbi，也可能得到字面量 `"null"`。
- `ConvertAbi` 执行 `pm install -r --abi`，会重新安装应用；不会生成缺失的架构库，也不保证分包可用。abi 使用 mem.arm/arm64/x86/x64，检查 output 和 ok。
