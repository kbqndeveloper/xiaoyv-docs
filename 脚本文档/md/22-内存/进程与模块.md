# 进程与模块

查询进程、选择目标、查看模块映射，或暂停和恢复进程。

**方法名称：** 进程与模块查询（Android）。

**语法：** 见下方方法表。

**参数说明：** `name` 用于进程精确匹配或模块路径子串匹配；`pattern` 用于带通配符的进程查询。PID 为整数。

| 方法 | 参数 | 返回值 | 说明 |
|---|---|---|---|
| `mem:get_pid(name: string)` | name：完整进程名 | mem: XiaoYvMemory（table）, pid: integer | 精确匹配进程名并选为当前目标，找不到时抛错 |
| `mem:set_pid(pid: integer)` | pid：目标进程 ID | mem: XiaoYvMemory（table） | 设置目标并刷新位数 |
| `mem:get_pidX(pattern: string)` | pattern：进程名模式，支持 *、? | rows: XiaoYvMemProcess（table）[] 或 nil, error: string | 查询进程，支持 * 和 ? |
| `mem:getProcessArchitecture(pid?: integer)` | pid：可选，默认当前目标 | bits: integer | 查询目标位数；省略使用当前目标 |
| `mem:getModuleInfo(name: string)` | name：映射路径子串 | rows: XiaoYvMemModule（table）[] 或 nil, error: string | 按路径子串查询各段映射 |
| `mem:pause_process()` | 无 | ok: boolean | 向当前目标发送 SIGSTOP |
| `mem:resume_process()` | 无 | ok: boolean | 向当前目标发送 SIGCONT |

| 返回值 | 说明 |
|---|---|
| mem, pid | get_pid 的第一个返回值是对象，第二个才是 PID |
| rows | 普通数组；没有匹配项返回空数组，查询失败返回 nil 和错误信息 |
| bits | 32 或 64；查询失败返回负值 |
| ok | 暂停或恢复信号是否发送成功，不代表已等待目标完成状态切换 |

## 示例

```lua
local mem = require("mem"):new()

-- 先查询候选进程，再按准确名称选择。
local candidates, err = mem:get_pidX("com.example.*")
assert(candidates, err)
for _, row in ipairs(candidates) do print(row.pid, row.cmdline) end
local _, pid = mem:get_pid("com.example.app")
print(pid, mem:getProcessArchitecture())

local modules, queryError = mem:getModuleInfo("libexample.so")
assert(modules, queryError)
for _, row in ipairs(modules) do
    print(string.format("0x%X", row.start), row.size, row.perms, row.path)
end
```

## 使用说明

- `get_pid` 精确匹配 cmdline 首段名称；`get_pidX` 使用 fnmatch 通配模式，不改变当前目标。
- `set_pid` 更新 PID 和 `mem.arch`，不保证目标仍存在或可访问。
- 模块按路径子串匹配，同一 SO 的不同映射分别返回。`start` 是单段起点，不一定是计算函数地址所需的加载基址。
- 暂停和恢复影响整个进程；返回 true 只表示信号发送成功。

**类型：** `XiaoYvMemProcess`（table）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| pid | integer | 是 | 进程 ID |
| cmdline | string | 是 | 进程名 |

**类型：** `XiaoYvMemModule`（table）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| start | integer | 是 | 单段映射起点 |
| size | integer | 是 | 单段映射字节数 |
| perms | string | 是 | 权限，例如 rw-p |
| path | string | 是 | 映射路径，不合并同一 SO 的多段 |
