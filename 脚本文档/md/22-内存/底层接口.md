# 底层内存接口

公开入口 `require("xiaoyv.mem.native")` 与 `mem.native` 相同。所有方法用冒号调用，显式传 PID，适合自定义封装。

**方法名称：** 底层内存接口（Android）。

**语法：** 见下方方法表。

**参数说明：** 地址和 PID 使用整数，size 为字节数；typeName 的可选值见页末。

| 方法 | 参数 | 返回值 | 说明 |
|---|---|---|---|
| `native:find_process(name: string)` | name：完整进程名 | pid: integer | 精确匹配进程名；未找到或失败返回 -1 |
| `native:processes(pattern: string)` | pattern：进程名通配模式 | rows: XiaoYvMemNativeProcess（table）[]\|nil | 按 shell 通配模式查询进程，例如 com.example.*；无匹配为空数组，失败 nil |
| `native:modules(pid: integer, pattern: string)` | pid：目标进程 ID；pattern：路径子串，空串匹配全部 | rows: XiaoYvMemNativeModule（table）[]\|nil | 按映射路径子串过滤；空串匹配全部，每条 maps 记录单独返回 |
| `native:bits(pid: integer)` | pid：目标进程 ID | bits: integer | 读取目标 ELF 位数，成功为 32/64，失败为负数 |
| `native:read(pid: integer, address: integer, size: integer)` | pid：目标进程 ID；address：目标地址；size：字节数，>0 | bytes: string\|nil | size 必须大于 0；读取原始字节，失败 nil |
| `native:write(pid: integer, address: integer, bytes: string)` | pid：目标进程 ID；address：目标地址；bytes：原始字节字符串 | ok: boolean | 按字符串实际长度写入，保留嵌入 NUL，不自动加终止符 |
| `native:read_typed(pid: integer, address: integer, typeName: XiaoYvMemNativeNumberType)` | pid：目标进程 ID；address：目标地址；typeName：数值类型，见页末 | value: number\|nil | 整数类型返回 integer，float/double 返回 number；失败 nil |
| `native:write_typed(pid: integer, address: integer, value: number, typeName: XiaoYvMemNativeNumberType)` | pid：目标进程 ID；address：目标地址；value：待写数值，整数类型要求整数；typeName：数值类型 | ok: boolean | 整数类型要求 value 可表示为 Lua 整数，按目标类型宽度转换 |
| `native:pages_present(pid: integer, address: integer, size: integer)` | pid：目标进程 ID；address：起始地址；size：字节数，允许 0 | present: boolean | 按 pagemap 检查页面；size 可为 0；不是读写权限保证 |
| `native:permissions(pid: integer, address: integer)` | pid：目标进程 ID；address：目标地址 | permissions: string\|nil | 查询地址所属映射的权限文本，如 rw-p；失败 nil |
| `native:mprotect(pid: integer, address: integer, perm: string)` | pid：目标进程 ID；address：目标地址；perm：权限文本，如 rw- | status: integer | 修改地址所在页面权限，如 rwx；成功 0，失败 -1 |
| `native:scan(request: string)` | request：包含 pid 的搜索 JSON 字符串 | addresses: integer[]\|nil | 接收包含 pid 的搜索 JSON；无匹配为空数组，失败 nil；不额外排序 |
| `native:symbol(path: string, name: string)` | path：本地 ELF 文件路径；name：符号名 | value: integer | 查询本地 ELF 文件中的符号值，失败 0；不是目标运行时地址 |
| `native:mmap64(pid: integer, address: integer, size: integer, prot: integer, flags: integer, fd: integer, offset: integer)` | pid：目标进程 ID；address：建议地址，0 为自动选择；size：字节数；prot/flags：权限及映射标志；fd：文件描述符；offset：文件偏移；均必填 | address: integer | 在目标进程申请映射，失败 0；所有参数必填 |
| `native:call(pid: integer, address: integer, args?: integer[])` | pid：目标进程 ID；address：目标函数地址；args：最多 32 个整数或指针，省略或 nil 表示无参数 | value: integer, error: string? | 远程调用，参数最多 32 个整数或指针；省略或 nil 表示无参数 |
| `native:inject(pid: integer, path: string)` | pid：目标进程 ID；path：对目标可见的 SO 绝对路径 | error: string? | 在目标加载绝对路径 SO；成功 nil，失败错误字符串 |
| `native:set_backend(mode: integer)` | mode：0=S、1=K、2=P，必填 | 无 | 切换共享读取方式：0=S、1=K、2=P；mode 必填 |
| `native:init_kernel()` | 无 | ok: boolean | 初始化 K 客户端，需要设备具备匹配驱动 |
| `native:kernel_read(pid: integer, address: integer, size: integer)` | pid：目标进程 ID；address：目标地址；size：字节数，>0 | bytes: string\|nil | 直接走 K 读取，size 必须大于 0；失败 nil |
| `native:signal(pid: integer, signalNumber: integer)` | pid：目标进程 ID，>0；signalNumber：信号编号，19 暂停、18 继续 | ok: boolean | 向 pid>0 的进程发信号；19 暂停、18 继续 |
| `native:unity_read(pid: integer, address: integer)` | pid：目标进程 ID；address：Unity 字符串对象地址 | text: string\|nil | 读取 Unity 字符串对象，返回 UTF-8，失败 nil |
| `native:unity_read_instance(pid: integer, instance: integer, offset: integer)` | pid：目标进程 ID；instance：实例地址；offset：字段偏移，必填 | text: string\|nil | 从实例字段取得字符串指针；offset 必填，无默认值 |
| `native:unity_write(pid: integer, address: integer, text: string)` | pid：目标进程 ID；address：Unity 字符串对象地址；text：UTF-8 文本 | ok: boolean | 向 Unity 字符串对象写入 UTF-8 文本 |
| `native:unity_write_instance(pid: integer, instance: integer, offset: integer, text: string)` | pid：目标进程 ID；instance：实例地址；offset：字段偏移，必填；text：UTF-8 文本 | ok: boolean | 从实例字段取得字符串指针后写入；offset 必填 |
| `native:utf8_to_utf16(text: string)` | text：UTF-8 文本 | bytes: string | 返回 UTF-16LE 字节，不附加终止符；遇首个零码元截断 |
| `native:utf16_to_utf8(bytes: string)` | bytes：偶数字节的 UTF-16LE 字符串 | text: string | 输入必须为偶数字节的 UTF-16LE；输出遇首个零字节截断 |
| `native:http_get(url: string)` | url：明文 HTTP 地址 | body: string\|nil, status: integer | 简单明文 HTTP GET；成功状态 0，失败非零 |
| `native:http_download(url: string, path: string)` | url：明文 HTTP 地址；path：保存路径 | status: integer | 简单明文 HTTP 下载到文件；成功 0，失败非零 |
| `native:file_md5(path: string)` | path：本地文件路径 | hex: string\|nil, status: integer | 返回文件的 32 位小写十六进制 MD5；成功状态 0 |

| 返回值 | 说明 |
|---|---|
| ok / status | ok=true 或 status=0 表示成功；status 不是 HTTP 响应码 |
| value, error（call） | error=nil 才表示成功；失败时忽略 value |
| error（inject） | nil 表示成功，字符串表示失败 |
| 其他 | 失败值见方法表；非法参数通常抛错，返回的字符串和表无需手动释放 |

## 示例

```lua
local native = require("xiaoyv.mem.native") -- 也可用已有对象的 mem.native
local pid = native:find_process("com.example.app")
assert(pid > 0, "没有找到进程")

-- address 指向业务代码确认的小端 int32 + float 结构。
local bytes = assert(native:read(pid, address, 8), "读取失败")
local id, value = string.unpack("<i4f", bytes)
print(id, value)

local result, err = native:call(pid, functionAddress, {integerArg})
assert(err == nil, err)
print(result)
```

搜索直接传入 JSON，固定结构中用 %d 保留整数精度：

```lua
local request = string.format(
    '{"pid":%d,"rangs":[{"Star":%d,"End":%d}],"head":{"type":"int32_t","data":%d},"max":16}',
    pid, startAddress, endAddress, 100)
local hits = assert(native:scan(request), "搜索失败")
table.sort(hits)
for _, address in ipairs(hits) do print(string.format("0x%X", address)) end
```

## 使用说明

- `read/write` 使用原始字节字符串；写 C 字符串需自行添加 `"\0"`，UTF-16LE 终止符为 `"\0\0"`。窄整数写入按类型宽度转换，不检查溢出。
- `scan` 不自动填 PID、不排序。搜索 uint8/uint16 写成 `u_int8_t`/`u_int16_t`，数值读写用 `uint8_t`/`uint16_t`。JSON 编码需保留整数精度，空集合用数组；配置见[内存搜索](内存搜索.md)。
- `call` 检查第二返回值；`inject` 成功返回 nil。两者与上层返回形式不同。
- `set_backend` 与上层共用设置；底层无常量字段，可使用 mem 的[常量](常量附录.md)。

通用约定见[入门](Memory.md)；功能限制分别见[远程操作](远程操作.md)、[内存读取方式](内存读取方式.md)、[Unity](指针链与Unity.md)和[辅助功能](辅助功能.md)。

## 类型与结果字段

| 对象 | 类型 | 说明 |
|---|---|---|
| `native` | XiaoYvMemNative（table） | require("xiaoyv.mem.native") 或 mem.native 返回的模块 |

| 类型别名 | 类型 | 说明 |
|---|---|---|
| XiaoYvMemNativeNumberType | "int8_t"\|"int16_t"\|"int32_t"\|"int64_t"\|"uint8_t"\|"uint16_t"\|"uint32_t"\|"uint64_t"\|"char"\|"unsigned char"\|"float"\|"double" | read_typed/write_typed 接受的数值类型；字符串和二进制用 read/write |

**类型：** `XiaoYvMemNativeProcess`（table）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| pid | integer | 是 | 进程 ID |
| name | string | 是 | cmdline 首个 NUL 前的进程名；上层 get_pidX 将该字段改名为 cmdline |

**类型：** `XiaoYvMemNativeModule`（table）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| start | integer | 是 | 此条映射的起始地址，不保证就是 ELF 加载基址 |
| size | integer | 是 | 映射长度，单位字节 |
| permissions | string | 是 | 权限文本；上层 getModuleInfo 将该字段改名为 perms |
| path | string | 是 | 映射路径或名称，可能为空 |
