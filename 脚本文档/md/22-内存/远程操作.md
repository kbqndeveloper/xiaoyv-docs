# 远程操作

在目标进程中调用函数、申请映射或加载 SO。函数地址和指针参数必须属于目标进程。

**方法名称：** 目标进程中的函数与映射（Android）。

**语法：** 见下方方法表。

**参数说明：** address 是目标地址，args 是最多 32 项的整数/指针数组。remoteMmap 的 size 为字节数，prot/flags 为按位组合的常量；匿名映射通常用 fd=-1、offset=0。

| 方法 | 参数 | 返回值 | 说明 |
|---|---|---|---|
| `mem:getFunctionAddress(path: string, name: string)` | path：本地 ELF 文件路径；name：符号名 | value: integer | 从 ELF 文件查询符号值，不自动加目标加载基址 |
| `mem:remoteMmap(address: integer, size: integer, prot: integer, flags: integer, fd: integer, offset: integer)` | address：建议地址，0 为自动选择；size：字节数；prot/flags：权限及映射标志；fd：文件描述符，匿名用 -1；offset：文件偏移，匿名用 0 | address: integer | 在当前目标进程申请映射 |
| `mem:remoteCallFunction(address: integer, args?: integer[])` | address：目标函数地址；args：最多 32 个整数或指针，默认空数组 | value: integer 或 error: string | 调用目标地址，最多 32 个整数或指针参数；省略 args 使用空数组 |
| `mem:injector(path: string)` | path：对目标可见的 SO 绝对路径 | ok: boolean, error: string? | 在目标进程加载指定绝对路径的 SO |

| 返回值 | 说明 |
|---|---|
| value（符号查询） | ELF 中的函数符号值；失败为 0，不是直接可调用的目标运行时地址 |
| address（分配） | 目标映射地址；当前实现失败返回 0，包括目标 mmap 返回 MAP_FAILED 的情况 |
| value 或 error（调用） | 成功为整数，失败为错误字符串；需先检查 type |
| ok, error（注入） | 成功 true；失败 false 并附带错误信息 |

## 示例

### 调用与注入

```lua
-- functionAddress 是已解析的目标函数地址。
local result = mem:remoteCallFunction(functionAddress, {integerArg, targetPointer})
if type(result) == "string" then error(result) end
print("返回值", result)

local ok, err = mem:injector("/data/local/tmp/libexample.so")
assert(ok, err)
```

### 分配、写入与释放

munmapAddress 是目标进程中 munmap 的真实地址。

```lua
local size = 4096
local address = mem:remoteMmap(0, size,
    mem.PROT_READ | mem.PROT_WRITE,
    mem.MAP_PRIVATE | mem.MAP_ANONYMOUS, -1, 0)
assert(address ~= 0, "分配失败")

-- 即使写入抛错，也继续尝试释放。
local completed, written, writeError = pcall(mem.write_memory, mem, address, "Hello", mem.str)
local released = mem:remoteCallFunction(munmapAddress, {address, size})
assert(type(released) == "number" and released == 0, "释放失败: " .. tostring(released))
assert(completed, written)
assert(written, writeError)
```

## 使用说明

- `getFunctionAddress` 返回本地 ELF 文件中的符号值，不是可直接调用的目标地址。需使用与目标一致的文件，结合 ELF 布局和加载位置计算；不能任取一条可执行映射起点相加。
- 调用只支持最多 32 个整数或指针参数，不自动传字符串、结构体或浮点寄存器参数。
- 正常调用没有默认 5 秒超时，目标函数不返回时可能一直等待。同一目标的远程操作串行，不同目标可并行。
- 错误可能包含现场恢复或分离失败，不能据此认为目标已经恢复。主动申请的映射需自行释放。
- 注入路径必须对目标可见，SO 架构匹配目标；不返回 dlopen 句柄或函数地址。
