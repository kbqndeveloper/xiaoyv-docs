# Java 互操作

`import` 返回 Java Class 或只读包代理。脚本用局部变量保存结果，不会产生简单类名全局变量：

```lua
local lang = import("java.lang.*")
local util = import("java.util.*")
local Context = import("android.content.Context")
local LuaEngine = import("com.nx.assist.lua.LuaEngine")

print(lang.Math.sin(1.2))
print(lang.System.currentTimeMillis())

local context = LuaEngine.getContext()
print(context.getPackageName())
print(Context.ACTIVITY_SERVICE)

local values = util.ArrayList()
values.add("b")
values.add("a")
print(values.size(), values[0], #values)
```

## 已支持语义

- 完整类名返回 Java Class；`package.*` 返回延迟解析、带缓存的只读包代理。
- 可把 `ClassLoader` 或具有 `loadClass(String)` 的 Java 对象作为第二参数。
- 支持静态和实例字段、方法、构造函数、公开内部类、重载与链式调用。
- 支持 Java 数组、`List`、`Map` 下标及 `#object` 长度。
- Lua function 可转换为单抽象方法接口，Lua table 可转换为多方法接口监听器。
- Java 异常转换为 Lua 错误，可用 `pcall` 捕获。
- `nil` 与 Java `null` 双向转换；Java `void` 方法没有返回值。

```lua
local Runnable = import("java.lang.Runnable")
local runnable = Runnable(function()
    print("Java Runnable 回调")
end)
runnable.run()
```

## 类型转换

| Lua | Java 参数 |
|---|---|
| `nil` | 非 primitive 的 `null` |
| boolean | `boolean` / `Boolean` |
| integer | 按范围匹配 `int`、`long` 等整数类型 |
| number | 优先匹配 `double`，也可转换为 `float` |
| string | `String` / `CharSequence` / 单字符 `char` |
| Java userdata | 原 Java 对象 |
| table | Java 数组、`List`、`Collection`、`Map` 或接口代理 |
| function | 单抽象方法 Java 接口代理 |

Java `String`、boolean、整数和浮点数返回 Lua 基础类型，其他 Java 对象保持 userdata。
Lua table 转数组或集合时读取 `1..n` 连续部分；Java 数组和 `List` 使用 Java 的 `0` 起始下标。

## 生命周期与回调

Java 对象和接口代理由当前脚本运行期管理。Java 回调会回到当前脚本环境依次执行，不会并发
修改 Lua 状态。同步方法等待回调完成；异步监听器进入脚本回调队列。脚本结束后旧代理再次
触发会明确报错。

## LuaEngine 兼容类

需要这些 Java 方法时先保存类返回值：

```lua
local LuaEngine = import("com.nx.assist.lua.LuaEngine")
local context = LuaEngine.getContext()
```

当前提供 `getContext`、HTTP、邮件、`loadApk`、`getExtensionPath`、截图 Bitmap、截图缓存和
结束回调等方法。`loadApk` 返回的加载对象可直接传给 `import(className, loader)`。
