**方法名称：** 触控与手势。

**语法：** 见下方方法表。

**参数说明：**

| 方法 | 参数 | 返回值 |
|---|---|---|
| `touchDown([id,] x, y)` | 可选手指 ID 和按下坐标 | 无 |
| `touchMove([id,] x, y)` | 可选手指 ID 和移动坐标 | 无 |
| `touchUp([id,] x, y)` | 可选手指 ID 和抬起坐标 | 无 |
| `tap(x, y[, duration])` | 坐标、可选按住毫秒数，默认 `30` | 无 |
| `longTap(x, y[, duration])` | 坐标、可选按住毫秒数，默认 `500` | 无 |
| `touchMoveEx(id, x, y, duration)` | 手指 ID、终点和毫秒时长 | 无 |
| `swipe(x1, y1, x2, y2[, duration])` | 起止坐标、可选毫秒时长 | 无 |

| 返回值 | 说明 |
|---|---|
| 无 | 这组操作不返回内部触控注入状态。 |

**详细说明：**

`touchDown`、`touchMove`、`touchUp` 的手指 ID 可以省略，省略时为 `1`；抬起时必须提供终点坐标。所有坐标均为真实屏幕像素。`touchUp(...)` 会先移动到给定终点，再抬起该手指。

```lua
-- 省略手指 ID，使用默认手指 1。
touchDown(540, 960)
sleep(30)
touchMove(560, 940)
touchUp(560, 940)

-- 多指时显式指定手指 ID。
touchDown(2, 200, 1500)
touchMoveEx(2, 800, 500, 300)
touchUp(2, 800, 500)

tap(540, 960, 40)
longTap(540, 960, 800)
swipe(200, 1500, 800, 500, 400)
```
