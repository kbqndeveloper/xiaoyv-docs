**方法名称：** 在当前截图区域中查找圆形。

**语法：** `opencv.findCircles(x1, y1, x2, y2[, options])`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `x1, y1, x2, y2` | `integer` | 是 | 物理截图区域，端点均包含；全为 `0` 时表示全屏。 |
| `options` | `table` | 否 | 霍夫圆参数，字段见下表。 |

| options 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `dp` | `number` | `1` | 累加器分辨率与原图分辨率的反比，必须大于 `0`。 |
| `minDistance` | `number` | `20` | 圆心之间的最小距离。 |
| `edgeThreshold` | `number` | `100` | Canny 边缘检测高阈值。 |
| `centerThreshold` | `number` | `30` | 圆心累加器阈值；越小通常检测到更多圆。 |
| `minRadius` | `integer` | `0` | 最小半径。 |
| `maxRadius` | `integer` | `0` | 最大半径；`0` 表示由 OpenCV 决定上限。 |

| 返回值 | 说明 |
|---|---|
| `table` | `{ {x=圆心横坐标, y=圆心纵坐标, r=半径}, ... }`；没有命中时为空。 |

**详细说明：**

坐标和半径均使用当前物理截图像素。参数无效、区域越界或处理失败时抛出 Lua 错误。

```lua
local circles = opencv.findCircles(0, 0, 0, 0, {
    dp = 1.6,
    minDistance = 10,
    edgeThreshold = 230,
    centerThreshold = 40,
    minRadius = 12,
    maxRadius = 20,
})

for _, circle in ipairs(circles) do
    print(circle.x, circle.y, circle.r)
end
```
