# OpenCV

`opencv` 是独立的只读全局命名空间，不随 `m`、`lr`、`cd` 切换，也不需要 `import`。它同时提供截图算法入口和 OpenCV 4.9.0 AAR 中的 Java 顶层类：

| 入口 | 说明 |
|---|---|
| [`opencv.capture`](capture.md) | 从当前截图缓存创建 RGBA `Mat`。 |
| [`opencv.findCircles`](查找圆形.md) | 使用霍夫圆检测返回圆心和半径。 |
| `opencv.Mat`、`opencv.Imgproc`、`opencv.Core` 等 | 直接访问构建所用 AAR 中的 Java 类。 |

```lua
local image = opencv.capture(0, 0, 31, 31)
local gray = opencv.Mat()
opencv.Imgproc.cvtColor(image, gray, opencv.Imgproc.COLOR_RGBA2GRAY)

print(gray:cols(), gray:rows())
gray:release()
image:release()
```

类名在构建时从实际解析到的 OpenCV AAR 生成，不按包顺序猜测。访问未知类返回 `nil`；`opencv` 不会向 `_G` 写入 `Mat`、`Imgproc` 等简单类名。类、字段和方法以 [OpenCV 4.9.0 Java API](https://docs.opencv.org/4.9.0/javadoc/)为准。

基础 APK 只保留 Java 类。首次访问任一 OpenCV 类或算法时，引擎会按顺序加载已导入的 `opencv/<abi>/libc++_shared.so` 和 `opencv/<abi>/libopencv_java4.so`。文件缺失、ABI 不符或 linker 失败都会直接抛出 Lua 错误。
