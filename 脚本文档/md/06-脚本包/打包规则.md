# 脚本包

`.alpkg` 是脚本和资源的单文件包。项目根目录使用 `alpkg.json`：

```json
{
  "entry": "main.lua",
  "include": [
    "main.lua",
    "*.lua",
    "scripts/",
    "images/"
  ],
  "exclude": [
    ".git/",
    ".vscode/",
    "dist/",
    "test*",
    "dev*",
    "*.bak"
  ]
}
```

`include` 必填且不能为空。`"main.lua"` 表示明确文件，`"*.lua"` 只匹配项目根目录的 Lua 文件，`"scripts/"`、`"images/"` 才会递归读取对应目录。打包器不会进入其他未列出的目录。

`exclude` 在 `include` 范围内继续过滤。不带路径前缀的 `"test*"`、`"*.bak"` 会匹配其中任意层级的文件或目录名；带路径的规则只匹配对应项目相对位置。入口最终未被包含或被排除时，打包失败。明确文件不存在时会报错，未匹配的通配符或目录会提示后跳过。

首次打包缺少 `alpkg.json` 时，打包器会自动创建上述默认配置并继续执行；已有配置缺少 `include` 时会提示补充白名单，不会退回全项目遍历。

包内 Lua 文件由打包器转换为可运行格式；`require("modules.task")`、`dofile("common/config.lua")`、`m.web.open({ file = "ui/index.html" })` 仍按项目相对路径使用。HTML、JS、CSS、图片等资源不加密，直接从包内读取。HTML 内的 `href`、`src` 等相对路径同样以页面所在目录为基准，例如 `ui/index.html` 可以直接引用 `style.css`、`app.js` 和 `images/logo.png`。
