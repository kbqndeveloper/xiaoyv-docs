**方法名称：** 在当前截图缓存中执行原生多点找色。

**语法：** `findColors(x1, y1, x2, y2, dir, sim, colors)`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `x1, y1, x2, y2` | `integer` | 是 | 锚点查找范围，边界包含在内。 |
| `dir` | `integer` | 是 | 扫描方向，取值 `1..8`。 |
| `sim` | `integer` | 是 | 默认 RGB 容差，写作 `0xRRGGBB`。 |
| `colors` | `string` | 是 | 颜色描述，格式见下文的颜色规则。 |

| 返回值 | 说明 |
|---|---|
| `integer, integer` | 找到时返回命中基准点的 `x, y`。 |
| `nil, string` | 未找到或处理失败时返回原因。 |

**详细说明：**

这是小鱼原生 `m.findColors` 接口，直接使用当前截图缓存，不需要额外的“是否截屏”参数。它的方向约定为 `1..8`；与本分类的兼容找色接口不能混用方向。坐标使用真实截图像素。

需要全部结果时使用 [findColorsAll](查找全部多点颜色.md)。

```lua
local x, y = findColors(
    0, 0, 1079, 1919,
    2,
    0x101010,
    "0|0|FFFFFF|0.0.100-0.5.5,10|5|FF0000-101010"
)

if x then
    print("找到", x, y)
end
```

## 颜色规则

格式为 `x|y|候选1|候选2,...`：不同点用逗号分隔。同一点的候选为“或”，不同点为“且”，允许混合 RGB、HSV 和反色。

| 候选写法 | 含义 |
|---|---|
| `aabbcc` | RGB 颜色，使用 `sim` 的默认偏色 |
| `aabbcc-101010` | RGB 颜色及自己的偏色 |
| `@aabbcc-101010` | 不在该 RGB 颜色及偏色范围内 |
| `120.80.90` | HSV 颜色，偏色为 `0.0.0` |
| `120.80.90-5.10.10` | HSV 颜色及自己的偏色 |
| `@120.80.90-5.10.10` | 不在该 HSV 颜色及偏色范围内 |

RGB 使用六位十六进制，支持大小写和 `0x` 前缀；`sim` 是 RGB 三通道偏色，不是相似度百分比，也不作用于 HSV。颜色与偏色须使用同一种模式，以 `-` 连接。旧写法 `aabbcc|101010` 现在表示两个颜色候选，若原意是偏色，应改为 `aabbcc-101010`。

`@` 只对当前候选的完整匹配结果取反，不会否决其他候选。例如 `aabbcc|@334455-101010` 表示匹配前者，或者不在后者的偏色范围内。

HSV 颜色和偏色均为十进制整数 `H.S.V`，H 为 `0..360`，S、V 为 `0..100`。像素转换后的 HSV 四舍五入到整数；色相按圆周最短距离比较，`360` 等同于 `0`，无彩色的 H 为 `0`，H 偏色达到 `180` 时覆盖全部色相。

首个描述点为锚点，其余点的偏移为自身坐标减去首点坐标，描述坐标可以为负数。返回锚点坐标；搜索范围含边界，只约束锚点，其余点可超出搜索范围，但必须位于输入截图或图片内。

最多支持 500 个描述点；空候选、尾随逗号、残缺描述、越界数值及颜色与偏色模式不一致均为格式错误。
