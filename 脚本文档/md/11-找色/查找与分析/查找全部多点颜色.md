**方法名称：** 在当前截图缓存中查找全部多点颜色。

**语法：** `findColorsAll(x1, y1, x2, y2, dir, sim, colors)`

**参数说明：**

参数格式、颜色规则、容差和扫描方向与 `findColors()` 完全一致。

| 返回值 | 说明 |
|---|---|
| `table` | 按扫描方向返回全部匹配点；每项为 `{x = integer, y = integer}`。未找到时返回空表。 |
| `nil, string` | 截图或参数处理失败时返回原因。 |

**使用示例：**

```lua
local points = findColorsAll(
    0, 0, 1079, 1919,
    2,
    0x101010,
    "0|0|FFFFFF,10|5|FF0000-101010"
)

for _, point in ipairs(points) do
    print(point.x, point.y)
end
```

**详细说明：**

该函数与 `findColors()` 使用同一张截图缓存和同一套匹配规则，区别仅在于它会继续扫描并收集全部命中坐标。
