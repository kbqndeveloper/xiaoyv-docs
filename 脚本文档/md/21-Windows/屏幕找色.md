# 屏幕找色

**方法名称：** 直接在大漠截图缓存中执行高速多点找色。

**语法：**

`findColors(screenData, x1, y1, x2, y2, dir, sim, colors)`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `screenData` | integer | 是 | `dm.GetScreenData(x1, y1, x2, y2)` 返回的点阵地址，像素格式为 `0x00RRGGBB`。 |
| `x1, y1, x2, y2` | integer | 是 | 描述 `screenData` 对应的截图区域。 |
| `dir` | integer | 是 | `1~8`，扫描方向与 Android `findColors` 一致。 |
| `sim` | integer | 是 | RGB 容差，例如 `0x101010`。 |
| `colors` | string | 是 | `x|y|RRGGBB` 多点规则，使用逗号连接。 |

| 返回值 | 说明 |
|---|---|
| `x, y` | 命中时返回屏幕绝对坐标；未找到或参数无效返回 `-1, -1`。 |

**详细说明：**

`colors` 中每个颜色点也可写成 `x|y|RRGGBB-RRGGBB`，末尾颜色表示该点独立使用的
RGB 容差；未写独立容差时使用 `sim`。

| `dir` | 扫描顺序 |
|---|---|
| `1` | 从左到右，每列从上到下 |
| `2` | 从上到下，每行从左到右 |
| `3` | 从上到下，每行从右到左 |
| `4` | 从右到左，每列从上到下 |
| `5` | 从右到左，每列从下到上 |
| `6` | 从下到上，每行从右到左 |
| `7` | 从下到上，每行从左到右 |
| `8` | 从左到右，每列从下到上 |

```lua
local x1, y1, x2, y2 = 100, 100, 800, 600
local screenData = dm.GetScreenData(x1, y1, x2, y2)
local x, y = findColors(
    screenData,
    x1, y1, x2, y2,
    2,
    0x101010,
    "0|0|FF0000,10|5|00FF00"
)
```

`screenData` 由大漠插件自动管理，脚本不需要调用 `FreeScreenData`。`findColors` 不保存、
不复制也不释放该地址，只在本次调用期间读取点阵。
