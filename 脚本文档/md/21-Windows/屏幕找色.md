# 屏幕找色

**方法名称：** 直接在大漠截图点阵中执行高速多点找色。

**语法：**

`findColors(screenData, width, height, x1, y1, x2, y2, dir, sim, colors)`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `screenData` | integer | 是 | `dm.GetScreenData` 返回的点阵地址，像素格式为 `0x00RRGGBB`。 |
| `width, height` | integer | 是 | `screenData` 对应截图的实际宽高。 |
| `x1, y1, x2, y2` | integer | 是 | 截图内首点的搜索范围，包含边界，以截图左上角为 `(0,0)`。 |
| `dir` | integer | 是 | `1~8`，与 Android 一致，见[方向示意与选择](../11-找色/扫描方向.md)。 |
| `sim` | integer | 是 | 默认 RGB 三通道偏色，例如 `0x101010`；不作用于 HSV。 |
| `colors` | string | 是 | 颜色描述，格式见[多点颜色规则](../11-找色/查找与分析/原生多点找色.md#颜色规则)。 |

| 返回值 | 说明 |
|---|---|
| `x, y` | 命中时返回锚点在截图内的坐标；未找到、参数或颜色格式无效时返回 `-1, -1`。 |

**详细说明：**

`width、height` 用于像素寻址，必须与传入截图一致。搜索范围只限制首点，其他描述点可以超出搜索范围，但必须在截图内。返回坐标以截图左上角为 `(0,0)`；需要屏幕坐标时，加上截图在屏幕上的起点。需要全部命中时使用 [findColorsAll](屏幕全部找色.md)。

```lua
local dm = require("xiaoyv_hcbyj") -- 此例使用 x86 大漠插件
local left, top, right, bottom = 100, 100, 800, 600
-- 大漠点阵宽高按坐标差计算，不加 1。
local width, height = right - left, bottom - top
local screenData = dm.GetScreenData(left, top, right, bottom)
local x, y = findColors(
    screenData, width, height,
    0, 0, 200, 200,
    2,
    0x101010,
    "0|0|FF0000|0.100.100-5.10.10,10|5|00FF00"
)
if x >= 0 then
    print("截图坐标", x, y)
    print("屏幕坐标", x + left, y + top)
end
```

`screenData` 由大漠插件自动管理，脚本不需要调用 `FreeScreenData`。`findColors` 不保存、不复制也不释放该地址，只在本次调用期间读取点阵。
