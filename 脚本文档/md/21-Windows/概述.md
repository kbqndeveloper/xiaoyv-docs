# Windows 第一版

Windows 使用 x64 中控和独立的 x86 Worker 进程。中控负责增减 Worker、启动/暂停/继续、停止、
常驻状态和滚动日志；每个中控窗口对应一个进程、一条 Named Pipe、一个 Lua VM 和一个大漠对象。
某个 Worker 崩溃或断联不会影响其他窗口；中控立即回收其进程并保留日志，再次点击“启动”会
用新 Pipe 创建新进程。

Lua 与中控的交互边界见[中控交互](中控交互.md)：脚本使用 `print` 和 `print_user` 上报内容，
生命周期控制由中控完成，第一版没有 Lua 读取或反向控制中控的接口。

中控不带参数启动时，自动按同目录 `dev.lua`、`main.alpkg` 的顺序选择脚本。`dev.lua` 用于
直接开发调试，可通过 `require/loadfile/dofile` 加载同目录的相对 Lua 文件。

当前可用：

- `print`、`print_user`、`sleep` 和 `thread`；
- `httpGet/httpPost/asynHttpGet/asynHttpPost`；
- LuaSocket 的 TCP/UDP 和非 TLS 上游模块；
- `ffi`、`require("ffi")`；
- `require("opencv")`：按需加载 OpenCV 5，入口为 `cv`；
- [`require("db")`](数据库/概述.md)：按需加载 SQLite 数据库，支持预编译语句、游标、事务和可选 SQLite3MC 加密；
- `U2G/G2U`；
- `dm.*` 大漠兼容函数；框架不自动展开到全局。

分模块帮助： [多线程](多线程/概述.md)、[网络与 FFI](网络与FFI/概述.md)、[stb 图像处理](stb图像处理/概述.md)、
[OpenCV 5](OpenCV/概述.md) 和 [SQLite 数据库](数据库/概述.md)。

第一版不照搬 Android `pai`，也不提供设置页、WebView2、`e_print`、WebSocket、
`ssl.https`、加密、个性化 VM 和定制大漠偏移自动识别。
