# 屏幕全部找色

**方法名称：** 在大漠截图点阵中查找全部多点颜色。

**语法：** `findColorsAll(screenData, width, height, x1, y1, x2, y2, dir, sim, colors)`

**参数说明：**

**参数引用：** [findColors](屏幕找色.md)

参数及颜色规则与 [Windows 屏幕找色](屏幕找色.md) 相同。

| 返回值 | 说明 |
|---|---|
| `table` | 按 `dir` 顺序返回全部命中，每项为 `{x = integer, y = integer}`，坐标以截图左上角为 `(0,0)`；未找到返回 `{}`。 |
| `nil, string` | 参数、颜色格式或内存处理失败时返回原因。 |

**详细说明：**

结果按 `dir` 顺序返回，每个锚点只返回一次，不合并相邻命中、不截断；使用 `#points` 获取数量。截图管理与 `findColors` 相同。

```lua
local points, err = findColorsAll(screenData, width, height, x1, y1, x2, y2, 2, 0, "0|0|0.100.100-5.10.10")
if points then print("数量", #points) else print(err) end
```
