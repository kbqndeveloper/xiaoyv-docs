# x64 服务与 x86 客户端示例

此例不依赖额外插件。把两段代码分别保存为 `rpc_server.lua` 和 `rpc_client.lua`，使用中控的架构选择器和“添加其他脚本”分别添加窗口。先启动 x64 服务，看到“计算服务已就绪”后，再启动一个或多个 x86 客户端窗口。

## rpc_server.lua

```lua
local rpc = require("rpc")
local server = assert(rpc.listen("xiaoyv.compute.demo"))

-- 可以在本脚本 require x64 插件，只导出其他 Worker 需要的业务函数。
server:export("sum", function(values)
    local total = 0
    for _, value in ipairs(values) do total = total + value end
    return total, #values
end)
server:export("echoBytes", function(bytes)
    return bytes -- 二进制字符串不经过 JSON 或 UTF-8 转换
end)

print_user("计算服务已就绪")
assert(server:run())
```

## rpc_client.lua

```lua
local rpc = require("rpc")
local client = assert(rpc.connect("xiaoyv.compute.demo", 5000))

local total, count = client:call("sum", {10, 20, 30})
if total == nil then
    client:close()
    error(count) -- 调用失败时第二项是错误信息
end
print("合计：", total, "数量：", count)

local bytes = assert(client:call("echoBytes", "A\0B"))
print("返回字节数：", #bytes) -- 3
client:close()
```

x86 服务供 x64 调用的写法完全相同，只需在中控选择对应架构；插件必须匹配服务所在 Worker 的位数。多个客户端使用相同服务名称，服务端逐个处理请求。

HTML 页面创建窗口也可以指定架构：

```javascript
const path = await center.pickFile(); // 选择 rpc_server.lua
if (path) {
  const id = await center.add({path, arch: "x64", name: "计算服务"});
  await center.start(id);
}
```

创建和启动成功不代表服务已进入 `run`。客户端连接使用有界等待；连接失败时先检查服务端日志，不要用无限重试掩盖脚本错误。结束示例时停止各窗口即可。
