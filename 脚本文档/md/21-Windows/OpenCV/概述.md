# OpenCV 5

**方法名称：** 在 Windows Worker 中使用 OpenCV 5。

**语法：**

`require("opencv")`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 无 | - | - | OpenCV 函数的参数见对应函数的 OpenCV 5 文档。 |

| 返回值 | 说明 |
|---|---|
| `cv` | OpenCV 5 的 Lua 入口表；加载失败时抛出 Lua 错误。 |

**详细说明：**

先将与窗口位数相同的 `opencv.dll` 和 `opencv_world500.dll` 放入 `runtime/x86/` 或 `runtime/x64/`，再用 `local cv = require("opencv")` 加载。

图片路径使用 UTF-8。函数使用 `cv.imread(...)` 等写法，对象方法使用 `image:empty()` 等写法；输出图片通常由返回值取得。

## 常用函数

下面这些页面只覆盖 Windows Worker 中最常见的图片处理流程，参数顺序按当前 Lua 绑定书写：

- [Mat 对象](Mat对象.md)：创建、判断为空、复制和读取基本信息。
- [imread](imread.md)、[imwrite](imwrite.md)：读取和保存图片。
- [cvtColor](cvtColor.md)：颜色空间转换。
- [resize](resize.md)：缩放图片。
- [threshold](threshold.md)、[inRange](inRange.md)：二值化和范围筛选。
- [GaussianBlur](GaussianBlur.md)、[Canny](Canny.md)：滤波和边缘检测。
- [findContours](findContours.md)、[drawContours](drawContours.md)：轮廓查找和绘制。
- [matchTemplate](matchTemplate.md)、[minMaxLoc](minMaxLoc.md)：模板匹配和结果定位。

`imread` 默认通道顺序为 BGR；转换颜色时使用 `cv.COLOR_BGR2GRAY` 等对应常量。

## 当前可用范围

当前插件绑定的 OpenCV 5.0.0 SDK 提供 `core`、`imgproc`、`imgcodecs`、`videoio`、`highgui`、`dnn`、`features`、`flann`、`photo`、`objdetect`、`calib`、`geometry`、`stereo`、`stitching` 和 `ptcloud` 模块。常见图像处理、特征、视频读写、DNN 推理等接口可从 `cv` 使用。

暂不包含 `opencv_contrib` 和 CUDA；具体 Lua 参数与返回值见各函数页。

OpenCV 5 官方文档：<https://docs.opencv.org/5.0/>。

## 使用示例

```lua
local cv = require("opencv")
local image = cv.imread("input.png", cv.IMREAD_COLOR)
assert(not image:empty(), "图片读取失败")
local gray = cv.cvtColor(image, cv.COLOR_BGR2GRAY)
assert(cv.imwrite("gray.png", gray))
```
