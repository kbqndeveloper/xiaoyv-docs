# OpenCV 5

**方法名称：** 在 Windows Worker 中使用 OpenCV 5。

**语法：**

`require("opencv")`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 无 | - | - | OpenCV 函数的参数见对应函数的 OpenCV 5 文档。 |

| 返回值 | 说明 |
|---|---|
| `cv` | OpenCV 5 的 Lua 入口表；加载失败时抛出 Lua 错误。 |

**详细说明：**

`require("opencv")` 成功后返回 `cv` 表。OpenCV DLL 在此时才加载；未调用 `require` 的脚本不会占用 OpenCV 运行时内存。图片路径使用 UTF-8，中文路径无需调用 `U2G()`。

OpenCV 是可选插件，默认构建不包含。使用前准备与 Worker 位数一致的 `opencv.dll` 和 `opencv_world500.dll`，放入 `runtime/x86` 或 `runtime/x64`。不能用 x86 DLL 在 x64 Worker 内加载；需要跨位数使用时，通过 [RPC](../RPC/概述.md) 调用另一个 Worker 的业务函数。

常用全局函数、常量和类名基本沿用 OpenCV 5 的 C++ 命名，例如 `cv.imread`、`cv.cvtColor`、`cv.Mat`、`cv.dnn`。但这是 Lua 绑定，不完全等同 C++ 或 Python 写法：

- C++ 的输出参数通常省略后直接作为 Lua 返回值；也可以传入已有 `Mat` 作为输出对象。
- `Mat` 等对象成员用 Lua 的 `:` 调用，例如 `image:empty()`、`image:clone()`。
- 具体函数含义、算法参数和常量以 OpenCV 5 官方文档为准；Lua 侧以本页的调用规则为准。

## 常用函数

下面这些页面只覆盖 Windows Worker 中最常见的图片处理流程，参数顺序按当前 Lua 绑定书写：

## 读写与颜色转换

```lua
local cv = require("opencv")

local image = cv.imread("输入图片.png", cv.IMREAD_COLOR)
assert(not image:empty(), "图片读取失败")

-- 未传 dst 时，绑定自动创建并返回输出 Mat。
local gray = cv.cvtColor(image, cv.COLOR_BGR2GRAY)
assert(cv.imwrite("输出图片.png", gray))
```

`imread` 默认得到 BGR 通道顺序，不是 RGB。处理颜色时应使用对应常量，例如 `cv.COLOR_BGR2GRAY`、`cv.COLOR_BGR2HSV`。

## 当前可用范围

当前插件绑定的 OpenCV 5.0.0 SDK 提供 `core`、`imgproc`、`imgcodecs`、`videoio`、`highgui`、`dnn`、`features`、`flann`、`photo`、`objdetect`、`calib`、`geometry`、`stereo`、`stitching` 和 `ptcloud` 模块。常见图像处理、特征、视频读写、DNN 推理等接口可从 `cv` 使用。

没有编入 `opencv_contrib`、CUDA 等额外模块；这类官方文档中的接口不可直接假定存在。少数依赖复杂 C++ 模板或回调的接口也可能不适合 Lua 调用。OpenCV 4 已删除、改名或移动的接口不会在这里额外模拟兼容；旧脚本应按 OpenCV 5 的迁移说明调整。

OpenCV 5 官方文档：<https://docs.opencv.org/5.0/>。
