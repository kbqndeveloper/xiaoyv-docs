# 中控交互

用 `print` 输出日志、`print_user` 显示状态；用 `ui.call` 读取或更新中控页面，用 `ui.receive` 接收页面发送的数据。

下面的脚本可配合默认 HTML 的“更多 → 自定义示例”使用。运行后修改账号并点击“发送”，脚本就能收到新设置。

```lua
print_user("正在采集")                 -- 中控列表中的状态文本
print("任务开始")                     -- 中控日志

local settings, err = ui.call("getSettings") -- 读取页面中的账号
assert(not err, err)
print("当前账号：", settings and settings.account or "")

local _, statusErr = ui.call("setStatus", "等待设置") -- 更新页面文字
assert(not statusErr, statusErr)

while true do
    local name, data = ui.receive(1000) -- 等待页面事件，最多 1 秒
    if name == "settings" then
        print("新账号：", data.account)
        print_user("设置已更新")
    elseif name == nil and data ~= nil then
        error(data)
    end
end
```

函数说明：[print_user](print_user.md)、[ui.call](中控界面/call.md)、[ui.receive](中控界面/receive.md)。
