# 中控交互

Windows 中控的 Worker、状态和日志由原生层保存。有 `center.html` 时使用 HTML 显示层，没有时使用原生显示层；启动、暂停、停止等控制逻辑共用。页面刷新只会重建网页环境，不会停止 Worker；关闭中控会结束外置 Worker，并等待进程内脚本停止及清理。页面和脚本的查找规则见[开发与打包](开发与打包.md)。

普通窗口可选 x86、x64 或进程内：前两项使用独立进程，进程内的位数由中控决定。每个窗口有独立 Lua VM，但进程内窗口与[中控脚本](中控界面/中控脚本.md)共享中控进程及插件的进程级状态；其中的原生代码崩溃会影响整个中控。需要故障隔离或强制结束时请选择外置窗口。

Lua 与页面有两条业务通道：

- Lua 调用页面：页面先用 `ui.expose(name, callback)` 注册函数，Lua 再调用
  [`ui.call(name, data, timeoutMs)`](中控界面/call.md)。
- 页面投递事件：页面调用 `ui.send(workerId, name, data)`，对应 Worker 使用
  [`ui.receive(timeoutMs)`](中控界面/receive.md)接收。

网页侧完整接口见[HTML 中控自定义与 JavaScript 接口](中控界面/HTML自定义与JavaScript.md)。

原生模式下，有效的 `ui.call` 请求正常返回 `nil, nil`，不提示页面不可用；没有网页投递事件时，`ui.receive` 按等待时间返回空值。不要将此与独立运行 Worker 混淆：没有连接中控时，这两个接口会返回 `nil, error`。

## Lua 可以上报的内容

| Lua 写法 | 中控显示 | 行为 |
|---|---|---|
| `print(text)` | 当前 Worker 的滚动日志 | 追加一行，带 Worker 产生的时间戳。 |
| `print_user(text)` | 当前 Worker 的常驻状态行 | 覆盖上一条状态，不进入滚动日志。传入空字符串可清空。 |

```lua
print_user("正在采集")
print("本轮已处理：10")
```

常驻状态适合显示当前阶段、账号或任务摘要；详细过程和调试信息使用 `print`。

## 中控可以控制的内容

中控负责对选中的 Worker 发送以下控制：

- 启动：创建并运行 Lua VM；
- 暂停：请求暂停主任务和子线程；
- 继续：恢复已暂停的 Worker；
- 停止：请求任务退出并释放运行时；
- 强制结束：仅外置窗口可用，立即结束进程，保留列表项和日志；
- 删除：外置窗口直接结束进程；进程内窗口须先停止并完成清理，再删除列表项。

暂停和停止都需要 Lua 到达运行时检查点。正在执行的大漠、FFI 或其他 native 调用不会被强行中断；如果 native 调用永久阻塞，外置窗口可以强制结束而不影响其他窗口，进程内窗口不能单独强杀。

## 状态与常驻文本

运行、暂停和停止等脚本状态由对应 Worker 进程上报；`connecting`、`disconnected` 和强制结束后的状态由中控维护。页面在收到后台变化通知并重新查询后更新显示。状态包括 `connecting`、`starting`、`running`、`pausing`、`paused`、`stopping`、`stopped`、`error` 和 `disconnected`。控制方法返回成功只表示命令已被中控接纳，不表示状态转换已经完成。

中控在生命周期变化时会自动更新常驻文本，例如“正在启动”“运行中”“已暂停”“正在停止”、“已停止”“已完成”和“运行失败”。因此，脚本设置的 `print_user` 内容可能被生命周期提示覆盖；Worker 继续运行后，脚本可以再次调用 `print_user` 设置自己的状态。

滚动日志是显示用途，不是持久化记录。中控为每个 Worker 最多保留 2000 行，另有总字符数上限，超出时删除最早内容。网页收到的是合并后的“有新日志”通知，应再按需调用 `center.logs` 拉取；默认模板在用户选中日志文本时暂不自动滚动。重要业务结果应由脚本自行保存或提交。

“强制结束”会立即结束选中的 Worker 进程，但保留列表项和日志；下次启动同一列表项时创建新进程。`workerId` 标识列表项，在进程重建后保持不变，不是 Windows 进程 ID。删除 Worker 则会同时删除列表项。外置 Worker 停止或报错并空闲一小时后，中控也可能释放其进程，下次启动仍沿用同一 `workerId`。

## JSON 数据规则

两端只传纯 JSON 数据，单份数据编码后最多 64 KiB，嵌套最多 32 层、最多约 10000 个值。图片、文件等大数据应传路径，不要直接放进消息。

Lua 可发送 `nil`、boolean、有限 number、有效 UTF-8 string 和 table。table 必须是以下一种：

- 只含字符串键的对象；空 table 也按对象 `{}` 发送；
- 从 `1` 开始连续整数键的数组。

循环引用、函数、线程、普通 userdata、混合键和稀疏数组会被拒绝。Lua table 无法用 `nil` 保留字段或数组位置，需要显式 JSON `null` 时使用 `ui.null`：

```lua
local value, err = ui.call("saveSettings", {
    account = "demo",
    proxy = ui.null,
    tags = {"A", ui.null, "C"}
})
```

页面返回或发送的 JSON 对象、数组会转成 Lua table；嵌套的 JSON `null` 转成同一个 `ui.null` 标记。最外层 JSON `null` 转成 Lua `nil`，因此判断 `ui.call` 是否失败时要同时检查第二个返回值 `error`。

数值通过 JavaScript `Number` 和双精度 JSON 数值传递。需要完整保留的 64 位整数、订单号或其他大整数 ID 应改用字符串，不要依赖整数往返后仍逐位相同。

JavaScript 可传 `null`、string、boolean、有限 number、普通对象和完整数组；顶层 `undefined` 按 `null` 处理。循环、函数、非普通对象、稀疏数组、嵌套 `undefined`、`NaN` 和无穷数会被拒绝。
