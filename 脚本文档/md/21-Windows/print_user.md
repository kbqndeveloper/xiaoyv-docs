# print_user

**方法名称：** 更新 Windows 中控常驻状态。

**语法：** `print_user(text)`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `text` | `string` | 是 | 要在当前 Worker 常驻状态行显示的文本。 |

| 返回值 | 说明 |
|---|---|
| 无 | 只上报状态，不返回结果。 |

**详细说明：**

`print_user(text)` 替换当前 Worker 在 Windows 中控里的一行常驻状态，不追加到滚动日志。适合显示当前阶段、账号或任务摘要；详细过程仍用 `print(...)`。

```lua
print_user("正在采集")
print("已处理第 10 项")
```

传入空字符串会清空常驻状态。

中控在启动、暂停、继续、停止、正常完成或运行失败时会自动写入生命周期提示，例如“运行中”、“已暂停”“已完成”和“运行失败”，这些提示可能覆盖脚本之前设置的内容。Worker 继续运行后，脚本可以再次调用本函数写入自己的状态。Lua 不能通过本函数读取中控状态，也不能控制中控按钮。
