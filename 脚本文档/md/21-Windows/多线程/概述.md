# Windows 多线程

Windows Worker 的 Lua 子线程由 native 线程承载，但仍共享同一个 Lua VM。进入 Lua 的代码会通过 VM Gate 串行执行；不同 Worker 之间的 VM、线程和状态互相独立。

## 入口

- [beginThread](beginThread.md)：启动子线程，不返回线程对象。
- [newThread](newThread.md)：启动子线程并返回可停止的线程对象。
- [stopThread](stopThread.md)：请求指定线程停止并等待退出。

`beginThread` 还可以通过 `thread.beginThread` 调用；`newThread` 使用 `thread.newThread` 调用。

## 运行规则

- 一个 Worker 同时最多运行 10 个用户子线程，超过限制会抛出 Lua 错误。
- 主任务和子任务共享 `_G`、全局 table、`package.loaded` 以及已注册的运行时模块；共享数据仍需自行设计同步规则。
- `sleep`、HTTP 请求等阻塞等待会释放 VM Gate，让同一 Worker 的其他任务继续运行。
- 暂停、停止和 `stopThread` 依赖 Lua 检查点；正在执行的 native 调用不会被强行中断。
- 子线程发生 Lua 错误时只结束该子线程并写入 Worker 日志，不直接结束主任务。
- Worker 结束时会请求并等待所属子线程退出，线程对象和 Lua 状态随后由运行时回收。

```lua
local running = true
local threadObject = thread.newThread(function()
    while running do
        print("子线程运行中")
        sleep(100)
    end
end)

sleep(500)
running = false
threadObject:stopThread()
```
