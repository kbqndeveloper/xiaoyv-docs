# 远控命令行工具

`xiaoyvremotectl.exe` 用于查询远控设备、连接设备、输入和截图。控制 Lua 脚本窗口请用[中控外部控制](中控外部控制.md)。

## 启用控制入口

远控主程序默认不开放命令行控制。先使用 `--enable-control` 启动或打开中控：

```powershell
XiaoYvRemote.exe --enable-control
```

使用同一 Windows 用户运行命令行工具。

## 基本语法

```powershell
xiaoyvremotectl.exe <command> [options]
```

设备相关命令使用 `--device`（简写 `-d`）指定设备编号。设备编号来自 `list` 返回的 `id`。没有指定设备时，中控依次尝试唯一的批量选择设备、唯一的预览设备，或在只有一个已登记设备时使用该设备；无法确定唯一设备时应显式指定 `--device`。

## 命令

| 命令 | 作用 | 主要参数 |
|---|---|---|
| `list` | 列出已登记设备，不启动新的设备会话。 | 无 |
| `status` | 查询设备当前连接状态和画面尺寸。 | `--device` |
| `open` | 打开设备独立控制窗口。 | `--device` |
| `connect` | 请求连接设备。 | `--device` |
| `disconnect` | 请求断开设备。 | `--device` |
| `reconnect` | 停止当前会话并重新连接设备。 | `--device` |
| `tap` | 在设备画面执行一次点击。 | `--device --x --y` |
| `swipe` | 从起点滑动到终点。 | `--device --x1 --y1 --x2 --y2 [--duration]` |
| `key` | 发送系统按键。 | `--device --key` |
| `text` | 向设备输入文本。 | `--device --text` |
| `screenshot` | 获取设备原图并保存为 PNG。 | `--device [-o/--output]` |

`tap` 和 `swipe` 的坐标都是 `0~1` 的归一化坐标，与设备实际分辨率无关。超出范围的坐标会被限制到边界。`swipe` 的 `--duration` 单位为毫秒，默认 `300`，有效范围为 `16~10000`。

`key` 支持以下值：

```text
back home appswitch power volumeup volumedown
```

示例：

```powershell
# 查询设备编号和状态
xiaoyvremotectl.exe list
xiaoyvremotectl.exe status --device adb:emulator-5554

# 连接、点击并返回主页
xiaoyvremotectl.exe connect -d adb:emulator-5554
xiaoyvremotectl.exe tap -d adb:emulator-5554 --x 0.5 --y 0.8
xiaoyvremotectl.exe key -d adb:emulator-5554 --key home

# 滑动、输入文本并截图
xiaoyvremotectl.exe swipe -d adb:emulator-5554 --x1 0.5 --y1 0.8 --x2 0.5 --y2 0.2 --duration 500
xiaoyvremotectl.exe text -d adb:emulator-5554 --text "小鱼精灵"
xiaoyvremotectl.exe screenshot -d adb:emulator-5554 --output .\screen.png
```

## 选项

| 选项 | 说明 |
|---|---|
| `-d, --device <id>` | 目标设备编号。 |
| `--x <value>`、`--y <value>` | 点击坐标，范围 `0~1`。 |
| `--x1 <value>`、`--y1 <value>` | 滑动起点，范围 `0~1`。 |
| `--x2 <value>`、`--y2 <value>` | 滑动终点，范围 `0~1`。 |
| `--duration <ms>` | 滑动时长，默认 `300`，限制为 `16~10000`。 |
| `--key <name>` | 系统按键名称。 |
| `--text <value>` | 要输入的文本。 |
| `-o, --output <path>` | 截图保存路径；相对路径按命令行工具当前目录解析。 |

## JSON 返回

除帮助文本外，工具输出一行 JSON，适合其他程序逐行读取。成功响应包含 `ok: true`；失败响应包含 `ok: false` 和 `error`。连接、断开和重连返回 `accepted: true` 只表示中控已接受请求，需要最终状态时再次执行 `status` 或 `list`。

`list` 的设备项字段如下：

| 字段 | 说明 |
|---|---|
| `id` | 后续命令使用的设备编号。 |
| `name` | 当前显示名称或备注。 |
| `mode` | `adb` 或 `lan`。 |
| `online` | 设备发现状态。 |
| `state` | 当前会话状态，如 `connecting`、`connected`、`stopping`、`error`、`disconnected`。 |
| `width`、`height` | 当前已取得的视频画面尺寸，尚未取得时可能为 `0`。 |

```json
{"ok":true,"devices":[{"id":"adb:emulator-5554","name":"emulator-5554","mode":"adb","online":true,"state":"connected","width":720,"height":1280}]}
```

`status` 返回 `device`、`state`、`width` 和 `height`；输入和窗口操作通常返回 `device`；截图成功返回实际写入的 `path`：

```json
{"ok":true,"device":"adb:emulator-5554","state":"connected","width":720,"height":1280}
```

截图未指定 `--output` 时，文件写入系统临时目录下的 `xiaoyv-remote` 文件夹，并在响应中返回完整路径。截图始终请求设备原图，不是中控界面的缩略卡片。

## 退出码

| 退出码 | 含义 |
|---|---|
| `0` | 请求成功。 |
| `1` | 命令行参数或命令格式无效。 |
| `2` | 中控未使用 `--enable-control` 启动，或本机控制入口连接失败。 |
| `3` | 等待中控响应超时。 |
| `4` | 中控返回业务失败，具体原因见 JSON 的 `error`。 |
