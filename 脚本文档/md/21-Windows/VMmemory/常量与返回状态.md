# VMmemory 常量与返回状态

以下名称都属于 `local vm = require("VMmemory")` 返回的模块表，不会展开到全局。

## 状态码

只有 `vm.OK` 表示完整成功。其他状态通常返回 `nil, error, status`；搜索、批量等方法可能另附详情，见各函数页。

| 常量 | 值 | 含义 |
|---|---|---|
| `vm.OK` | 0 | 完整成功。 |
| `vm.BUFFER_TOO_SMALL` | 1 | 输出容量不足。 |
| `vm.PARTIAL` | 2 | 部分读取、写入或扫描完成。 |
| `vm.LIMIT_REACHED` | 3 | 达到搜索结果上限，不表示已经扫描完。 |
| `vm.CANCELLED` | 4 | 操作取消或任务停止。 |
| `vm.TIMEOUT` | 5 | 到达操作超时。 |
| `vm.INVALID_ARGUMENT` | -1 | 参数、范围或类型无效。 |
| `vm.INVALID_HANDLE` | -2 | 会话无效或已关闭。 |
| `vm.RUNTIME_ERROR` | -3 | 运行库、环境或底层运行错误。 |
| `vm.NOT_FOUND` | -4 | 找不到目标。 |
| `vm.READ_ONLY` | -5 | 会话或数据源不可写。 |
| `vm.IO_ERROR` | -6 | 内存访问失败。 |
| `vm.ABI_MISMATCH` | -7 | 接口或第三方结构版本不匹配。 |
| `vm.INTERNAL_ERROR` | -8 | 内部异常。 |
| `vm.NOT_EXECUTED` | -9 | 批量项未执行。 |

返回详情不是通用数据：单次读取可能只有完成字节数，批量结果按项给状态，搜索结果可含已有地址。不要仅按 `status >= 0` 判断成功。

## 地址和映射

| 常量 | 值 | 含义 |
|---|---|---|
| `vm.PHYSICAL_PID` | 0xffffffff | 在支持的方法中表示物理内存，不是实际进程 PID。 |
| `vm.MAP_PTE` | 1 | 进程页表映射。 |
| `vm.MAP_VAD` | 2 | 进程虚拟地址区域描述。 |
| `vm.MAP_PHYSICAL` | 3 | 物理内存映射，需配合 `PHYSICAL_PID`。 |

## 读取、写入及刷新标志

同一组标志可用 Lua `|` 组合。不同组即使数值相同，也不能混用。

| 用途 | 常量 | 值 | 含义 |
|---|---|---|---|
| 读取参数 | `vm.READ_CACHED` | 1 | 允许使用数据缓存；默认 `0` 绕过数据缓存。 |
| 读取参数 | `vm.READ_NO_PAGING` | 2 | 禁止底层使用分页读取路径。 |
| 写入参数 | `vm.WRITE_VERIFY` | 1 | 写后回读核对。 |
| 写入结果 | `vm.IO_UNCERTAIN_WRITE` | 1 | 失败写入可能已经影响目标，不能认定完全未写。 |
| 写入结果 | `vm.IO_VERIFY_FAILED` | 2 | 回读与写入内容不一致。 |
| 刷新参数 | `vm.REFRESH_DATA` | 1 | 刷新数据缓存。 |
| 刷新参数 | `vm.REFRESH_TRANSLATION` | 2 | 刷新地址转换缓存。 |
| 刷新参数 | `vm.REFRESH_PROCESSES` | 4 | 刷新进程相关信息。 |

`READ_CACHED` 不等于快照一致性；读取默认绕过数据缓存也不等于刷新页表。

## 数值和文本类型

数值参数可传下列常量，也可传小写字符串。所有数值采用小端字节顺序。

| 常量 | 值 | 字符串 | 字节数 |
|---|---|---|---|
| `vm.U8` | 1 | `u8` | 1 |
| `vm.U16` | 2 | `u16` | 2 |
| `vm.U32` | 3 | `u32` | 4 |
| `vm.U64` | 4 | `u64` | 8 |
| `vm.I8` | 5 | `i8` | 1 |
| `vm.I16` | 6 | `i16` | 2 |
| `vm.I32` | 7 | `i32` | 4 |
| `vm.I64` | 8 | `i64` | 8 |
| `vm.F32` | 9 | `f32` | 4 |
| `vm.F64` | 10 | `f64` | 8 |

`vm.TEXT_UTF8 = 1`，字符串写法为 `utf8`；`vm.TEXT_UTF16LE = 2`，字符串写法为 `utf16le`。读出的文本统一为 UTF-8，写入时也接收 UTF-8 文本。

## 能力位

`session:system().capabilities` 用以下位标志表达会话能力。它们不是打开参数，也不是当前操作成功的保证。

| 常量 | 值 | 能力 |
|---|---|---|
| `vm.CAP_READ` | 1 | 读取。 |
| `vm.CAP_WRITE` | 2 | 写入。 |
| `vm.CAP_LIVE` | 4 | 实时数据源。 |
| `vm.CAP_PROCESSES` | 8 | 进程信息。 |
| `vm.CAP_MODULES` | 16 | 模块信息。 |
| `vm.CAP_TRANSLATE` | 32 | 地址转换。 |
| `vm.CAP_BATCH` | 64 | 批量访问。 |
| `vm.CAP_SEARCH` | 128 | 内存搜索。 |
