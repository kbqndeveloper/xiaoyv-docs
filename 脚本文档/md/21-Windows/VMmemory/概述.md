# VMmemory 虚拟机内存

在 Windows 宿主机上读写虚拟机中的进程和内存。使用 x64 窗口，并先准备 [open](open.md) 页列出的运行库。

## 使用前准备

- 使用 VMware Workstation 15.5 及以上，保持虚拟机运行。
- Guest 关闭 TPM 和 Secure Boot。
- 以管理员权限运行，或确保当前进程拥有 `SeDebugPrivilege`。
- 取得宿主机 `vmware-vmx.exe` 的 PID，用于打开会话；后续读写使用虚拟机内的进程 PID。

## 使用顺序

1. `local vm = require("VMmemory")`，调用 [vm.open](open.md) 打开会话。
2. 用 [processes](会话/processes.md)、[module](会话/module.md) 找到进程和模块。
3. 用 [read](会话/read.md)、[read_value](会话/read_value.md)、[read_string](会话/read_string.md) 读取内容。
4. 需要写入时，在 `open` 中设置 `write = true`，再调用对应的写入函数。
5. 完成后调用 [close](会话/close.md)，或用 Lua `<close>` 自动关闭会话。

地址使用整数、字符串或 [vm.address](address.md)；不要用浮点数保存 64 位地址。会话方法的状态和部分结果见[常量与返回状态](常量与返回状态.md)，参数和示例见各函数页。
