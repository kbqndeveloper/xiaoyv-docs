# 交互数据

`ui.call`、`ui.receive` 和 JavaScript `ui.expose`、`ui.send` 使用 JSON 数据。

| 数据 | Lua 写法 | JavaScript 写法 |
|---|---|---|
| 文本、布尔值、数值 | string、boolean、有限 number | string、boolean、有限 number |
| 对象 | 只有字符串键的 table | 普通对象 |
| 数组 | 从 1 开始、整数键连续的 table | 完整数组 |
| 空值 | 顶层用 `nil`，table 内用 `ui.null` | `null` |

空 table 按对象传递。接收时，对象和数组转为 Lua table；顶层 `null` 转为 `nil`，嵌套 `null` 转为 `ui.null`。判断 `ui.call` 是否失败，应检查第二个返回值。

- 单份数据最多 64 KiB，嵌套最多 32 层、约 10000 个值；图片等大数据传文件路径。
- 不传函数、循环引用、混合键或稀疏数组；JavaScript 还不接受非普通对象、嵌套 `undefined`、`NaN` 和无穷数。顶层 `undefined` 按 `null` 处理。
- 需要完整保留的 64 位整数或长编号使用字符串。

```lua
local result, err = ui.call("saveSettings", {account = "demo", proxy = ui.null})
if err then print(err) end
```
