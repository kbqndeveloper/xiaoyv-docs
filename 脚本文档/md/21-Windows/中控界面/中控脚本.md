# 中控脚本 center.lua

文件位置：项目根目录的 `center.lua`，包模式下为包内同名文件；未指定项目时放在中控程序目录。中控启动后自动执行一次，刷新页面不会重新执行。

下面的 Lua `center` 函数仅供中控脚本使用，用于创建和控制窗口。页面中的同名对象见 [JavaScript 接口](JavaScript接口.md)。

**方法名称：** 中控脚本控制接口。

**语法：** 见下方方法表。

**参数说明：**

| 方法 | 参数 | 返回值 |
|---|---|---|
| `center.request(command: string, params?: table, timeoutMs?: integer)` | 命令名、参数表（默认空表）、可选超时毫秒 | `result: XiaoYvCenterResult（table） 或 nil, error: string` |
| `center.workers(timeoutMs?: integer)` | 可选超时；返回窗口消息数组、响应表，不含中控 Worker | `messages: table[], response: table 或 nil, error: string` |
| `center.logs(workerId: string, limit?: integer, after?: integer, timeoutMs?: integer)` | 窗口 ID、条数、游标、可选超时；返回日志消息数组、响应表 | `messages: table[], response: table 或 nil, error: string` |
| `center.add(path?: string, arch?: string, name?: string, timeoutMs?: integer)` | 返回新窗口 ID、响应表；只创建，不运行。`arch` 默认 `"x86"`，也支持 `"x64"`、`"inProcess"`；进程内模式使用中控自身位数 | `workerId: string, response: table 或 nil, error: string` |
| `center.remove(workerId: string, timeoutMs?: integer)` | 删除窗口 | `result: XiaoYvCenterResult（table） 或 nil, error: string` |
| `center.start(workerId: string, timeoutMs?: integer)` | 启动脚本 | `result: XiaoYvCenterResult（table） 或 nil, error: string` |
| `center.pause(workerId: string, timeoutMs?: integer)` | 请求暂停 | `result: XiaoYvCenterResult（table） 或 nil, error: string` |
| `center.resume(workerId: string, timeoutMs?: integer)` | 继续脚本 | `result: XiaoYvCenterResult（table） 或 nil, error: string` |
| `center.stop(workerId: string, timeoutMs?: integer)` | 请求停止并清理 | `result: XiaoYvCenterResult（table） 或 nil, error: string` |
| `center.terminate(workerId: string, timeoutMs?: integer)` | 强制结束外置窗口，进程内不支持 | `result: XiaoYvCenterResult（table） 或 nil, error: string` |

**类型：** `XiaoYvCenterResult`（table）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `response` | `table` | 是 | 控制响应。 |
| `messages` | `table[]` | 是 | 查询消息数组。 |

| 返回值 | 说明 |
|---|---|
| 成功结果 | 各方法的返回结构见上表；`response` 为控制响应，`messages` 为查询消息数组。 |
| `nil, error` | 请求失败，第二返回值为错误文本。 |

**详细说明：**

上述方法失败均返回 `nil, error`。可选超时沿用 [ui.call](call.md) 的规则；控制成功只表示命令已接纳，实际运行状态从 `center.workers()` 返回的 `state` 查看。`add` 不传路径时沿用中控默认脚本；`arch` 只接受 `x86`、`x64` 或 `inProcess`。进程内窗口需要先停止并完成清理才能删除。

**使用示例：**

```lua
-- center.lua：创建一个外置 x86 窗口并运行默认脚本
local id, err = center.add(nil, "x86", "采集窗口")
assert(id, err)
local result, startErr = center.start(id)
assert(result, startErr)

local workers, response = center.workers()
assert(workers, response)
for _, worker in ipairs(workers) do
    print(worker.workerId, worker.workerArch, worker.state)
end
```

日志消息的 `id` 是序号，`text` 是正文；响应表 `data` 为 JSON 字符串，包含 `first`、`next` 游标。继续拉取时把 `next` 传给 `after`，

页面与中控脚本仍通过 [ui.call](call.md) 和 [ui.receive](receive.md) 交互：页面向 `ui.send("__center__", "settings", data)` 投递，中控脚本通过 `ui.receive()` 接收。需要持续接收事件时应在脚本里保留接收循环；脚本执行结束后不再接收。
