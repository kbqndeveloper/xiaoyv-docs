# 开发与打包

中控启动参数可指定一个 `.lua` 或 `.alpkg`；不带参数时，按以下顺序选择来源：

1. 中控同目录的 `dev.lua`；
2. 中控同目录的 `main.alpkg`；
3. 两者都不存在时，暂不设置普通窗口的默认脚本。

界面、中控脚本和普通窗口默认入口使用同一个来源，不跨目录或跨包补找：

| 启动来源 | 界面 | 自动运行的中控脚本 | 普通窗口默认入口 |
|---|---|---|---|
| `.lua` | 该脚本目录的 `ui/center.html` | 同目录 `center.lua` | 指定的 Lua 文件 |
| `.alpkg` | 包内 `ui/center.html` | 包内 `center.lua` | 打包配置的 `entry` |
| 未找到默认脚本 | EXE 同目录 `ui/center.html` | EXE 同目录 `center.lua` | 暂无 |

没有 `ui/center.html` 时使用原生界面；没有 `center.lua` 时不运行中控脚本。包模式使用包内文件；自定义页面和中控脚本需要加入打包白名单。更换项目后重新打开中控。

普通窗口需手动启动；[center.lua](中控界面/中控脚本.md) 随中控自动运行。独立打开 Worker 程序时执行其同目录的 `main.alpkg`。

## 打包

Windows 开发目录中的打包器位于 `.xiaoyv/xiaoyv_pack.exe`，同目录 `windows.key` 必须与 Worker 构建所用的 Key 对应。

例如在程序目录执行：

```powershell
.\.xiaoyv\xiaoyv_pack.exe "E:\我的项目"
```

参数是配置目录，打包器读取其中的 `alpkg.json`；无参数时使用当前工作目录，不默认遍历 EXE 的上级目录。配置不存在时自动生成，首次使用请核对入口、白名单和路径。

`input_path`、`output_path` 相对于配置目录解析。新生成配置的默认值为：

| 配置位置 | input_path | output_path |
|---|---|---|
| 普通项目目录 | `.` | `dist/main.alpkg` |
| `.xiaoyv` 目录 | `../` | `../dist/main.alpkg` |

第二个命令行参数可覆盖输出文件：

```powershell
.\.xiaoyv\xiaoyv_pack.exe "E:\我的项目" "E:\发布目录\main.alpkg"
```

项目必须使用带 `include` 白名单的 `alpkg.json`，详细规则见[脚本包打包规则](../06-脚本包/打包规则.md)。发布时将包命名为 `main.alpkg`，放在程序目录；运行端不需交付 `.xiaoyv/windows.key` 和打包器。

## 插件与目录

新增窗口可选 x86、x64 或进程内（与中控位数相同）。插件位数必须与运行窗口一致。

`require("名称")` 按以下顺序查找同名 DLL：

| Worker | 首选 | 文件不存在时继续查找 |
|---|---|---|
| x86 | `runtime/x86/名称.dll` | `runtime/名称.dll` |
| x64 | `runtime/x64/名称.dll` | `runtime/名称.dll` |

这些目录相对于运行程序所在位置；进程内窗口以中控 EXE 目录为准。普通第三方 DLL 可通过 [FFI](网络与FFI/FFI/概述.md) 调用。

- `xiaoyv_hcbyj.dll`：x86 大漠插件；本体 `hcbyj.dll` 仍在 Worker EXE 同目录。
- `db.dll`：分别提供 x86、x64 版本。
- `opencv.dll` 和对应 OpenCV SDK DLL：可选，默认构建不包含。
- `VMmemory.dll` 及依赖：可选，仅 x64，默认构建不包含。

`runtime` 下的 `luasocket/` 存放共用 Lua 文件。使用哪个插件就保留对应 DLL 及其依赖。Worker 间跨位数调用使用 [RPC](RPC/概述.md)，不能直接把 x64 DLL 加载到 x86 Worker 内。

普通双击或不带控制参数启动中控时，不会开放外部控制入口。需要由命令行脚本、AI 或其他本机工具控制 Worker 时，使用 `--enable-control` 启动中控；完整命令见[中控外部控制](中控外部控制.md)。

HTML 文件放在项目根目录的 `ui/center.html`；编辑方法见 [HTML 自定义](中控界面/HTML自定义与JavaScript.md)。HTML 界面需要安装 Microsoft Edge WebView2 Runtime。
