# 开发与打包

中控不带参数启动时，按以下顺序选择入口：

1. 中控同目录的 `dev.lua`；
2. 中控同目录的 `main.alpkg`；
3. 两者都不存在时，由用户选择 `.lua` 或 `.alpkg`。

`dev.lua` 用于开发调试，可以通过 `require/loadfile/dofile` 加载同目录内的相对 Lua 文件。

发布时使用 `xiaoyv_pack.exe`：

```powershell
cd "E:\我的项目"
xiaoyv_pack.exe
```

无参数时打包当前工作目录，默认生成 `E:\我的项目\dist\我的项目.alpkg`。也可以明确指定：

```powershell
xiaoyv_pack.exe "E:\我的项目" "E:\发布目录\main.alpkg"
```

项目必须使用带 `include` 白名单的 `alpkg.json`，详细规则见[脚本包打包规则](../06-脚本包/打包规则.md)。
完成后控制台显示实际打包的一级文件、一级目录统计、文件总数和包大小。发布时将生成的包命名为
`main.alpkg`，与 `XiaoYvCenter.exe`、`XiaoYvWorker.exe`、`hcbyj.dll` 及其余运行文件放在同一目录。
