# 大漠兼容入口

**方法名称：** 调用 Windows 旧大漠函数表。

**语法：**

`dm.FunctionName(...)`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `...` | 视函数而定 | 是 | 沿用旧 `dm.cpp/dm.h` 对应函数的参数顺序和类型。 |

| 返回值 | 说明 |
|---|---|
| 视函数而定 | 沿用旧工程对应函数的返回形状。 |

**详细说明：**

大漠是仅供 x86 Worker 加载的插件，脚本自行接收并命名返回的函数表；框架不预建全局 `dm`：

```lua
local dm = require("xiaoyv_hcbyj")
local hwnd = dm.FindWindow("", "窗口标题")
```

需要旧工程的全局写法时，可由脚本自行全部或按需导出：

```lua
for name, func in pairs(dm) do
    _G[name] = func
end
```

返回值、参数顺序和旧工程的对应函数保持一致。调用时使用 `dm.FunctionName(...)`，不要使用会额外传入 `self` 的冒号写法。

`runtime/x86/xiaoyv_hcbyj.dll` 是 Lua 插件，`hcbyj.dll` 是大漠本体，仍放在 Worker EXE 同目录。首次 `require` 才加载并创建对象；同一 Lua VM 重复加载复用对象，脚本结束、VM 释放时销毁对象。不同 Worker 不共享对象。插件目录回退规则见[开发与打包](开发与打包.md#插件与目录)。第一版只支持当前旧 DLL 的固定 RVA；更换其他定制版可能直接调用到错误地址，不能混用。
