# 大漠兼容入口

**方法名称：** 调用 Windows 旧大漠函数表。

**语法：**

`dm.FunctionName(...)`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `...` | 视函数而定 | 是 | 沿用旧 `dm.cpp/dm.h` 对应函数的参数顺序和类型。 |

| 返回值 | 说明 |
|---|---|
| 视函数而定 | 沿用旧工程对应函数的返回形状。 |

**详细说明：**

Windows 第一版把旧 `dm.cpp/dm.h` 函数放在 `dm` 表，不自动写入全局：

```lua
local hwnd = dm.FindWindow("", "窗口标题")
```

需要旧工程的全局写法时，可由脚本自行全部或按需导出：

```lua
for name, func in pairs(dm) do
    _G[name] = func
end
```

返回值、参数顺序和旧工程的对应函数保持一致。调用时使用 `dm.FunctionName(...)`，不要使用会额外传入
`self` 的冒号写法。

每个 Worker 进程有自己的 `dmsoft` 对象，并分别加载同目录的 `hcbyj.dll`。
第一版只支持当前旧 DLL 的固定 RVA；更换其他定制版可能直接调用到错误地址，不能混用。
