# HTTP

发送 HTTP/HTTPS 请求；需要等待结果时使用同步函数，需要回调时使用异步函数。

- [httpGet](httpGet.md)：同步 GET。
- [asynHttpGet](asynHttpGet.md)：异步 GET。
- [httpPost](httpPost.md)：同步 POST。
- [asynHttpPost](asynHttpPost.md)：异步 POST。

超时单位为秒，默认 30，可设为 1～300。请求头可传 table 或原始字符串；table 的名称和值必须是字符串且不能包含换行，名称不能包含冒号。URL 需正确编码。

收到 4xx/5xx 也会返回响应正文和状态码；连接失败、超时或响应体超过 64 MiB 才按请求失败返回。
