# Windows HTTP

Windows Worker 的 `httpGet`、`httpPost` 使用系统 WinHTTP，支持 `http://` 和 `https://`。
同步请求会等待响应；等待期间释放 Lua VM Gate，同一 Worker 的其他任务仍可运行。

## 方法

- [httpGet](httpGet.md)：同步 GET。
- [httpPost](httpPost.md)：同步 POST。
- [asynHttpGet](asynHttpGet.md)：在线程中执行 GET，并通过回调返回结果。
- [asynHttpPost](asynHttpPost.md)：在线程中执行 POST，并通过回调返回结果。

## 通用约定

- 超时默认 30 秒，可设置为 1~300 秒。
- 请求头可传 table 或原始字符串；table 的名称和值必须是字符串，不能包含换行，名称不能包含冒号。
- 成功响应返回正文、HTTP 状态码、响应头 table 和状态消息；服务端返回 4xx/5xx 仍属于成功收到响应。
- 单次响应体最大 64 MiB，超过限制会按请求失败返回错误。
- 请求 URL、正文和请求头使用 Lua 字符串；路径编码不适用于 URL，URL 应自行正确编码。
