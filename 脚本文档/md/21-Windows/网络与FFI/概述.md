# Windows 网络与 FFI

本目录记录 Windows Worker 独有的网络请求和原生 FFI 入口。HTTP 使用系统 WinHTTP，FFI 使用静态编入 Worker 的 cffi-lua；两者都不要求脚本额外加载 DLL。

## 页面分类

- [HTTP](HTTP/概述.md)：同步和异步 HTTP/HTTPS 请求。
- [FFI](FFI/概述.md)：C 声明、动态库加载、C 数据和回调。

LuaSocket 仍按标准写法 `require("socket")` 使用，公共 TCP/UDP 和 Lua 模块说明见[网络与通信](../../16-网络与通信/概述.md)。Windows 第一版不提供 `ssl.https`、WebSocket、文件上传和文件下载专用封装。
