# WebSocket

建立 `ws://` 或 `wss://` 长连接，通过回调接收连接、消息、错误和关闭事件。函数名和用法与 Android 一致。

- [startWebSocket](startWebSocket.md)：创建连接并注册回调。
- [sendWebSocket](sendWebSocket.md)：发送一条文本消息。
- [closeWebSocket](closeWebSocket.md)：请求关闭连接。

## 使用流程

1. 调用 `startWebSocket` 得到句柄，连接在后台建立；`onOpened` 触发后才能发送。
2. 在回调或其他线程中用 `sendWebSocket` 发送，收到的消息交给 `onRecv`。
3. 用 `closeWebSocket` 主动关闭，或等服务器关闭；最终都会触发一次 `onClosed`。
4. 主脚本结束时会关闭所有连接，需要持续通信时让主脚本保持运行。

```lua
local closed = false
local handle = startWebSocket("wss://example.com/ws",
    function(h) print("已连接") sendWebSocket(h, "hello") end,
    function(h, code, reason) print("已关闭", code, reason) closed = true end,
    function(h, message, code) print("出错", message, code) end,
    function(h, data) print("收到", data) end)

while not closed do
    sleep(100)
end
```

## 回调事件

| 回调 | 参数 | 触发时机 |
|---|---|---|
| `onOpened` | `handle` | 握手成功。 |
| `onRecv` | `handle, data` | 收到一条完整消息；文本和二进制都作为 Lua 字符串传入，二进制可含 `\0`。 |
| `onError` | `handle, message, code` | 连接失败或异常断开。`code` 是握手被拒时的 HTTP 状态码或系统错误码，没有时为 `0`。 |
| `onClosed` | `handle, code, reason` | 连接结束，每个连接只触发一次。 |

- 正常关闭只触发 `onClosed`；异常结束先触发 `onError`，再触发 `onClosed`，关闭码为 `1006`。重连逻辑可统一写在 `onClosed` 中。
- 同一连接的回调按事件到达顺序依次执行，不会并发。回调应尽快返回，耗时操作会推迟后续事件。
- 回调报错时该连接会被断开，错误按子线程报错输出，不影响其他连接。

## 运行规则

- 每个连接占用 1 个 Lua 子线程名额，与 `thread.newThread`、`asynHttpGet` 等共享上限 10。连接结束后名额自动归还。
- 连接超时为 10 秒，覆盖 DNS、TCP、TLS 和握手；关闭握手 3 秒内没有完成时，报告 `onClosed(handle, 1006, "关闭超时")`。
- 单条消息最大 16 MiB，超过时按异常断开。
- `wss://` 使用系统证书校验，证书无效时连接失败。
- 拔网线等情况下服务器无法发出关闭帧，连接可能长时间不报告断开。需要检测断网时，按服务器约定定时发送心跳：网络不通时发送最终会失败，并触发 `onError` 和 `onClosed`。
- 暂停脚本时回调也会暂停，期间收到的消息在恢复后依次交付。
- 需要 Windows 10 或更高版本。
