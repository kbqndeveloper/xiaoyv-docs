# Windows FFI

Windows Worker 内置 cffi-lua。以下三种入口引用同一个模块表：

```lua
local a = ffi
local b = require("ffi")
assert(a == b)
```

## 页面分类

- [声明与库加载](声明与库加载.md)：`ffi.cdef`、`ffi.C` 和 `ffi.load`。
- [C 数据与类型](C数据与类型.md)：创建 cdata、转换、布局、内存和字符串。
- [生命周期与回调](生命周期与回调.md)：GC、元类型、错误码和 Lua 回调。

当前按 Windows x86 ABI 验证。FFI 不会检查指针地址、缓冲区长度、调用约定或 DLL 导出签名；
声明错误可能直接导致 Worker 崩溃。优先使用项目正式 API，只有确实需要原生扩展时再使用 FFI。
