# Windows FFI

Windows Worker 内置 cffi-lua。以下两种入口引用同一个模块表：

```lua
local a = ffi
local b = require("ffi")
assert(a == b)
```

## 页面分类

- [声明与库加载](声明与库加载.md)：`ffi.cdef`、`ffi.C` 和 `ffi.load`。
- [C 数据与类型](C数据与类型.md)：创建 cdata、转换、布局、内存和字符串。
- [生命周期与回调](生命周期与回调.md)：GC、元类型、错误码和 Lua 回调。

支持 x86/x64 Worker，DLL 和声明必须匹配当前进程 ABI；不能在 x86 中直接加载 x64 DLL。可用 `ffi.sizeof("void *")` 区分 4 字节和 8 字节指针，跨 Worker 调用见 [RPC](../../RPC/概述.md)。FFI 不会检查指针地址、缓冲区长度、调用约定或 DLL 导出签名；声明错误可能直接导致 Worker 崩溃。优先使用项目正式 API，只有确实需要原生扩展时再使用 FFI。
