params: "cdata: cdata；callback/finalizer: function；metatable: table；errno: integer?"
returns: "cdata、ctype、integer 或无"
---

**方法名称：** 管理 cdata 生命周期、元类型、错误码和 Lua 回调。

**语法：**

```lua
ffi.gc(cdata, finalizer)
ffi.metatype(ctype, metatable)
ffi.errno([value])
ffi.cast(callbackType, function)
callback:set(function)
callback:free()
```

**参数说明：**

| 参数 | 类型 | 说明 |
|---|---|---|
| `cdata` | `cdata` | 要绑定或移除 finalizer 的数据。 |
| `finalizer` | `function` 或 `nil` | GC 回收 cdata 时调用；传 `nil` 可移除。 |
| `ctype` | `string` 或 ctype | 已声明的结构体或联合体类型。 |
| `metatable` | `table` | 定义 C 数据的 Lua 侧访问行为。 |
| `value` | `integer`（可选） | 设置当前线程的 C 错误码。 |
| `callbackType` | `string` 或 ctype | 非可变参数 C 函数指针类型。 |

| 返回值 | 说明 |
|---|---|
| `cdata` | `ffi.gc` 或 callback 转换结果。 |
| `ctype` | `ffi.metatype` 返回的类型对象。 |
| `integer` | `ffi.errno()` 返回当前线程错误码或设置前的值。 |
| 无 | `callback:set` 和 `callback:free` 成功时不返回值。 |

**详细说明：**

GC 时机不可预测，需要立即释放的原生资源应优先使用明确的释放函数。C 侧仍可能调用 callback 时，Lua 必须保留 callback 的强引用；确认 C 侧不再保存函数指针后再调用 `:free()`。callback 的调用约定必须与 DLL 一致，外部 native 线程不得直接回调 Lua。

```lua
local ffi = require("ffi")
ffi.cdef[[ typedef int (*xiaoyv_callback)(int); ]]

local callback = ffi.cast("xiaoyv_callback", function(value)
    return value + 1
end)
print(ffi.tonumber(callback(41)))
callback:free()
```
