# SQLite 连接

`db.open` 成功后返回连接 userdata。连接负责执行 SQL、创建预编译语句、管理事务和修改数据库密码。

- [connection:exec](exec.md)：执行一条不返回结果集的 SQL。
- [connection:query](query.md)：执行查询并返回游标。
- [connection:queryOne](queryOne.md)：只读取查询结果的第一行。
- [connection:prepare](prepare.md)：创建可重复使用的预编译语句。
- [connection:transaction](transaction.md)：执行带自动提交/回滚的事务回调。
- [connection:rekey](rekey.md)：修改当前数据库密码。
- [connection:ping](ping.md)：验证连接和数据库是否可读。
- [connection:close](close.md)：关闭连接并释放资源。

同一连接上的操作按顺序执行。游标仍在读取时，应先关闭游标，再关闭或复用所属语句和连接。
