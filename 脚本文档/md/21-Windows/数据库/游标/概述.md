# SQLite 查询游标

通过 [connection:query](../连接/query.md) 或 [statement:query](../预编译语句/query.md) 创建游标。游标逐行读取结果集，并在读完或关闭后释放查询占用。

- [cursor:fetch](fetch.md)：手动读取下一行。
- [cursor:rows](rows.md)：创建 `for` 循环迭代器。
- [cursor:columns](columns.md)：获取列名数组。
- [cursor:close](close.md)：立即结束读取并释放游标。

查询结果中的 NULL、BLOB 和行表规则见[数据类型与资源](../数据类型.md)。
