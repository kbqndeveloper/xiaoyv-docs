# Windows SQLite 数据库

Windows Worker 通过 `require("db")` 提供 SQLite 数据库能力。第一版只支持 SQLite，不提供 MySQL 等其他驱动。

## 基本流程

```lua
local db = require("db")
local conn = assert(db.open("sqlite", {
    path = "data/sample.sqlite",
    create = true,
}))

assert(conn:exec("CREATE TABLE IF NOT EXISTS user(id INTEGER PRIMARY KEY, name TEXT)"))
assert(conn:exec("INSERT INTO user(name) VALUES(?)", "小鱼"))

local row = assert(conn:queryOne("SELECT id, name FROM user WHERE name = ?", "小鱼"))
print(row.id, row.name)
conn:close()
```

## 运行环境

首次 `require("db")` 时按当前 Worker 位数加载 `runtime/x86/db.dll` 或 `runtime/x64/db.dll`；发布时保留所需位数的插件。目录回退规则见[开发与打包](../开发与打包.md#插件与目录)。数据库路径和 SQL 文本使用 UTF-8，`:memory:` 可用于打开内存数据库。

数据库操作失败通常返回 `nil, error`；Lua 参数类型错误仍可能直接抛出 Lua 错误。连接、语句和游标不用时应主动调用 `close`，Lua userdata 也会在回收时释放资源。

SQLite3MC 驱动编入 `db.dll`，不是 Worker。打开加密库时需要同时提供正确的 `key`、`cipher` 和 `compatibility`；可用名称以 [db.ciphers](模块/ciphers.md) 返回值为准。
