# SQLite 数据库

使用 `local db = require("db")` 打开 SQLite 数据库，执行 SQL、查询数据或使用事务。支持可选的数据库加密。

先调用 [db.open](模块/open.md) 获取连接，再按需要使用下面的函数：

| 对象 | 常用操作 |
|---|---|
| [模块](模块/概述.md) | 打开数据库、创建 BLOB、查询加密格式 |
| [连接](连接/概述.md) | 执行 SQL、查询、预编译、事务、关闭 |
| [预编译语句](预编译语句/概述.md) | 重复执行带参数的 SQL |
| [游标](游标/概述.md) | 逐行读取查询结果 |

参数绑定、NULL 和 BLOB 见[数据类型](数据类型.md)。不用的连接、语句和游标应调用 `close`。

## 对象类型

下面的名称用于说明参数和返回值类型，不需要在脚本中创建同名全局变量。

| 对象 | 类型 | 说明 |
|---|---|---|
| `db` | `XiaoYvDbModule`（table） | `require("db")` 返回的模块。 |
| `connection` | `XiaoYvDbConnection`（userdata） | `db.open` 返回的连接。 |
| `statement` | `XiaoYvDbStatement`（userdata） | `connection:prepare` 返回的预编译语句。 |
| `cursor` | `XiaoYvDbCursor`（userdata） | 查询返回的游标。 |
| `blob` | `XiaoYvDbBlob`（userdata） | `db.blob` 返回的绑定值。 |
| `null` | `XiaoYvDbNull`（userdata） | `db.NULL`，代表 SQL NULL。 |

| 类型别名 | 类型 | 说明 |
|---|---|---|
| `XiaoYvDbValue` | `integer\|number\|string\|XiaoYvDbNull（userdata）` | 查询单元格；BLOB 以二进制字符串返回。 |
| `XiaoYvDbRow`（table） | `table<string\|integer, XiaoYvDbValue>` | 查询行，支持列名和从 1 开始的列序号。 |

**类型：** `XiaoYvDbModule`（table）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `NULL` | `XiaoYvDbNull`（userdata） | 是 | SQL NULL 标记。 |
| `sqliteVersion` | `string` | 是 | SQLite 版本。 |
| `driverVersion` | `string` | 是 | 数据库驱动版本。 |
