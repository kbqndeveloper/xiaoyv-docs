**方法名称：** SQLite 参数、NULL、BLOB 和查询行的类型约定。

**语法：** `db.NULL`、`db.blob(binaryString)`、`row[columnName]`

**参数说明：**

| Lua 值 | 绑定的 SQLite 值 | 说明 |
|---|---|---|
| `nil` 或 `db.NULL` | `NULL` | 查询返回的 NULL 是 `db.NULL`，不要用 `nil` 比较 |
| `boolean` | 整数 `0` 或 `1` | SQLite 没有独立的布尔类型 |
| Lua 整数 | `INTEGER` | 按 64 位整数绑定 |
| Lua 数字 | `REAL` | 按浮点数绑定 |
| Lua 字符串 | `TEXT` | 按 UTF-8 文本绑定 |
| `db.blob(binaryString)` | `BLOB` | 用于保留二进制内容；查询返回 BLOB 时是 Lua 二进制字符串 |

| 返回值 | 说明 |
|---|---|
| `db.NULL` | SQL `NULL` 的唯一比较标记，也可以作为绑定参数 |
| `row` | 查询行表，同时支持 1-based 数字下标和列名键，例如 `row[1]`、`row.id` |
| `nil` | `queryOne` 没有查询到行，或 `cursor:fetch` 已读完 |
| `nil, error` | 数据库打开、SQL 准备、参数绑定、执行或读取失败 |

**使用示例：**

```lua
local db = require("db")
local conn = assert(db.open("sqlite", {path = ":memory:"}))

assert(conn:exec("CREATE TABLE sample(text_value TEXT, bytes BLOB, empty TEXT)"))
assert(conn:exec(
    "INSERT INTO sample(text_value, bytes, empty) VALUES(?, ?, ?)",
    "中文文本", db.blob("\0\1\2"), db.NULL
))

local row = assert(conn:queryOne("SELECT * FROM sample"))
assert(row.text_value == "中文文本")
assert(row.bytes == "\0\1\2")
assert(row.empty == db.NULL)
conn:close()
```

**详细说明：**

SQL 中的 `?` 或命名占位符按 SQLite 的绑定序号接收后续参数，参数数量必须完全匹配。表、函数、线程对象等其他 Lua 类型不能直接绑定；需要写入二进制时先调用 `db.blob`。

行表的数字下标按照查询列顺序从 `1` 开始；列名键使用 SQLite 返回的列名。不同列使用相同名称时，数字下标仍然保留，但同名列的列名键会被后面的列覆盖。
