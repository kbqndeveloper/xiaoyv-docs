# 数据库模块函数

`require("db")` 返回数据库模块表。模块本身不创建连接，连接由 [db.open](open.md) 创建。

- [db.open](open.md)：打开 SQLite 文件、内存库或可选加密数据库。
- [db.blob](blob.md)：把 Lua 字符串标记为 BLOB 绑定值。
- [db.ciphers](ciphers.md)：获取当前 SQLite3MC 驱动支持的加密格式名称。

模块还提供 `db.NULL`、`db.sqliteVersion` 和 `db.driverVersion` 字段，说明见[数据类型与资源](../数据类型.md)。
