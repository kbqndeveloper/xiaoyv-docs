# SQLite 预编译语句

通过 [connection:prepare](../连接/prepare.md) 创建的语句 userdata 可以重复绑定参数执行，适合批量写入或反复查询。

- [statement:exec](exec.md)：执行预编译的写入或结构 SQL。
- [statement:query](query.md)：执行预编译查询并返回游标。
- [statement:reset](reset.md)：在不关闭语句的情况下重置状态。
- [statement:close](close.md)：关闭预编译语句。

语句拥有游标时不能执行、重置或关闭；应先调用游标的 `close`。
