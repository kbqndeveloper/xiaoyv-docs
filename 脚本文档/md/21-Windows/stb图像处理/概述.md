# stb 图像处理

直接使用 `stb_image` 读取、修改和保存图片，无需 `require`。路径使用 UTF-8，像素坐标从 `(0, 0)` 开始，原始点阵为 RGB24。

- [load](load.md)：加载[可编辑图片](可编辑图片/概述.md)，读取或修改像素后保存。
- [read](read.md)、[write](write.md)：读取和写入 RGB24 点阵。
- [merge](merge.md)、[convert](convert.md)：合并图片、转换格式。
- [hsvThreshold](hsvThreshold.md)、[rgbToHsv](rgbToHsv.md)：HSV 二值化、颜色转换。
- [findColors](findColors.md)：在图片编码数据中多点找色；查屏幕用[屏幕找色](../屏幕找色.md)。
- [兼容入口](兼容入口.md)：旧名称对应关系。
