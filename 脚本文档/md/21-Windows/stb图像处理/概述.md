# Windows stb 图像处理

Windows Worker 内置 stb 图像处理库，独立于大漠。所有入口统一放在 `stb_image` 表中，图片路径使用 UTF-8；解码后的点阵统一为 RGB24（每个像素 3 字节，顺序为 R、G、B）。

## 基本用法

```lua
local image, error = stb_image.load("input.png")
assert(image, error)

local r, g, b = image:getPixel(10, 20, true)
image:setPixel(10, 20, 0xffff00)
assert(image:save("output.png", 100))
image:close()
```

## 函数分类

- [加载图片](load.md)：创建可编辑图片对象。
- [读取图片](read.md)：读取为宽、高和 RGB24 二进制字符串。
- [写入图片](write.md)：把 RGB24 二进制字符串写入图片文件。
- [合并图片](merge.md)：左右或上下合并两张图片。
- [HSV 二值化](hsvThreshold.md)：按 HSV 范围生成黑白图片。
- [格式转换](convert.md)：在 BMP、PNG 和 JPG/JPEG 之间转换。
- [RGB 转 HSV](rgbToHsv.md)：转换单个 `0xRRGGBB` 颜色。
- [图片多点找色](findColors.md)：在图片编码数据中执行八方向多点找色。
- [可编辑图片对象](可编辑图片/概述.md)：读取、修改和保存已加载图片的点阵。
- [兼容入口](兼容入口.md)：旧项目 `findColor` 和 `a1`~`a7` 名称映射。

图片坐标从 `0, 0` 开始。`findColors` 接收 PNG、BMP、JPG/JPEG 等图片的编码二进制字符串，与屏幕找色使用的是不同入口；屏幕点阵应使用 Windows 的全局 `findColors`。
