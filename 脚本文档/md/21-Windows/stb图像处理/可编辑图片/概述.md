# 可编辑图片对象

`stb_image.load` 返回的 userdata 持有一份 RGB24 点阵，可在原地读取、修改和保存。对象支持只读
`width`、`height` 字段；图片坐标从 `0, 0` 开始。

## 成员

- [getSize](getSize.md)：读取宽高。
- [getPixel](getPixel.md)：读取一个像素，可拆成 R、G、B。
- [setPixel](setPixel.md)：修改一个像素。
- [setPixels](setPixels.md)：批量修改像素。
- [getPixels](getPixels.md)：复制完整 RGB24 点阵。
- [getData](getData.md)：取得临时借用点阵地址。
- [save](save.md)：保存当前点阵。
- [close](close.md)：提前释放点阵。

`getPixels` 会复制数据，适合交给 Lua 保存或处理；`getData` 不复制，但地址只在图片对象未关闭
且仍被 Lua 引用时有效。图片对象不调用 `close` 也会在 Lua GC 时自动释放。
