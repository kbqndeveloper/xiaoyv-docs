# stb_image 兼容入口

为了兼容旧项目，`stb_image` 表保留旧的短名称。新脚本建议使用可读名称，参数和返回值完全相同。

| 兼容名称 | 当前名称 |
|---|---|
| `stb_image.a1` | `stb_image.merge` |
| `stb_image.a2` | `stb_image.hsvThreshold` |
| `stb_image.a3` | `stb_image.read` |
| `stb_image.a4` | `stb_image.write` |
| `stb_image.a5` | `stb_image.convert` |
| `stb_image.a6` | `stb_image.rgbToHsv` |
| `stb_image.a7` | `stb_image.findColors` |
| `stb_image.findColor` | `stb_image.findColors` |

`a1`~`a7` 只是同一 Worker 内的函数别名，不会改变图片格式、路径编码或内存生命周期规则。

```lua
local width, height, pixels = stb_image.a3("input.png")
local h, s, v = stb_image.a6(0xff8800)
```
