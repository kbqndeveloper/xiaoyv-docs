**方法名称：** 按调用层级输出日志。

**语法：** `printAt(level, ...)`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `level` | `integer` | 是 | 非负调用层数：`0` 记录当前打印位置，`1` 记录上一级调用位置，以此类推。 |
| `...` | `any` | 否 | 要打印的任意数量 Lua 值，多个值之间用制表符分隔。 |

| 返回值 | 说明 |
|---|---|
| 无 | 此方法不返回值。 |

**使用示例：**

```lua
printAt(0, "当前位置")

local function log(...)
    printAt(1, ...)
end

log("开始运行") -- 日志记录这一行的位置，而不是 log 函数内部的位置。
```

**详细说明：**

与 [print](print.md) 使用相同的日志输出方式，只改变日志记录的文件名和行号，不改变日志正文。可使用全局 `printAt` 或 `m.printAt`，并受 [setLogOff](setLogOff.md) 控制。

层数只计算用户 Lua 调用层，跳过平台内部包装和 `pcall` 等 C 调用层。用户自己封装的日志函数会占用一层，因此封装中通常使用 `printAt(1, ...)`。

层数超过现有调用栈，或所选层没有文件、行号信息时，内容仍正常输出，但不记录位置。负数、非整数或缺少层数参数会报错。

Lua 尾调用会消除调用层，已消除的位置无法恢复。封装日志函数时按示例直接调用，不要写成 `return printAt(1, ...)`。
