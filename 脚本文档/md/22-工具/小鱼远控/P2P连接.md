# P2P 连接

开始前，请向管理员取得信令地址和连接码。尚未部署服务器时，先看 [服务端部署](服务端部署.md)。电脑和手机均须更新到包含 P2P 功能的配套版本。

## 手机设置

1. 在小鱼精灵设置中开启“Root 模式”，完成设备的 Root 授权。
2. 打开“远控连接”的“设置”，连接方式选择“P2P 穿透”。
3. 填写信令地址，例如 `http://服务器公网IP:8080`。这里填服务器地址，**不是电脑或手机 IP**。
4. 填写管理员提供的连接码，至少 32 字符；与电脑保持完全一致，不带前后空白。
5. 默认不勾选“允许中继”，记录设置中显示的“设备编号”，保存。
6. 开启“远程控制”。状态显示“已上线，等待连接”后，在电脑端添加设备。

P2P 不需要填写手机监听端口，也不需要额外开启网络 ADB。当前手机端 P2P 远控需要 Root；非 Root 手机不能按这套步骤使用 P2P，原 ADB 连接方式不受此限制。

## 电脑设置

1. 打开小鱼远控，在“添加网络设备”中将“连接方式”选为 `P2P`。
2. 填写与手机相同的“信令地址”和“连接码”。
3. “设备编号”填写手机设置中的编号，**不是 IP、备注或 ADB 序列号**。
4. 按需填写备注、画质、采集来源、输入方式和分辨率上限；“允许中继”默认不勾选。
5. 确认添加。点亮设备名称可开启屏幕墙预览；双击打开独立控制窗口。

未开预览时打开的独立窗口，默认不显示视频，点击画面区域的“开启画面”即可。列表中的勾选负责同步/批量操作，不等于开启预览。

信令地址、连接码会保存，后续添加设备可以复用。需要修改时，右键对应设备选择“P2P 连接设置”；保存后会重连该设备。一个手机同时只接受一个主控连接，屏幕墙和该手机独立窗口可共用连接。

## 地址与中继

支持 HTTP 和 HTTPS，公网也可以直接使用 HTTP，无需域名或证书。HTTP 下连接码和信令明文传输；视频、操作和文件仍走独立的 P2P 通道。使用 HTTPS 时仍验证证书。地址不要带账号密码、查询参数或 `#` 片段；手机上的 `127.0.0.1` 指手机自己，不能用它访问电脑服务器。

需要中继时，先由管理员配置 TURN，再在手机与电脑两端勾选“允许中继”。仅勾选一端无效。允许中继仍会优先尝试直连；连接状态可显示实际使用的直连或中继路线。

## 常见问题

| 现象 | 检查方向 |
|---|---|
| 缺少 P2P 运行库 | 更新完整 APK，不要只替换脚本或远控 JAR |
| 请先开启 Root 模式 / Root 启动失败 | 开启 Root 模式并确认系统已授权 |
| 一直未上线、登记失败 | 核对信令地址、证书、服务器是否运行、连接码是否在服务器配置中 |
| 找不到设备或无法连接 | 确认手机已上线，两端连接码一致，设备编号无误；确认没有另一台电脑占用 |
| 显示打洞失败 | 核对 STUN 与 UDP 连通性；网络不支持直连时，可换网络或明确启用中继 |
| 窗口提示尚未开启画面 | 点击“开启画面”，不是黑屏故障 |
| 已连接但画面卡顿 | 先降低画质/分辨率；无损原画需要更多带宽，打洞成功不代表带宽充足 |

程序包含断线重连及手机默认网络切换后的重新登记逻辑，重建期间会短暂中断，不保证无缝切换。手机关闭“远程控制”会停止 P2P；系统结束 App 或限制后台运行也可能造成离线。
