---
params: "timeout: integer（可选）；index: integer；selector: selector"
returns: "node、node 数组、boolean 或 nil"
---

**方法名称：** 查询选择器匹配的节点，或直接操作匹配节点。

**语法：**

```lua
selector:findOne([timeout])
selector:findAll([timeout])
selector:findOnce(index[, timeout])
selector:exists([timeout])
selector:click()
selector:longClick()
node:findOne(selector[, timeout])
node:findAll(selector[, timeout])
```

**参数说明：**

| 参数 | 类型 | 说明 |
|---|---|---|
| `timeout` | `integer`（可选） | 等待匹配的毫秒数；省略或传 `0` 时只查询当前节点树。 |
| `index` | `integer` | `findOnce` 的匹配序号，从 `0` 开始。负数按 `0` 处理。 |
| `selector` | selector | `node:findOne`、`node:findAll` 在节点子树中使用的筛选条件。 |

| 返回值 | 说明 |
|---|---|
| node 或 `nil` | `findOne`、`findOnce` 返回匹配节点；没有匹配时返回 `nil`。 |
| node 数组 | `findAll` 返回全部匹配节点，没有匹配时返回空表。 |
| `boolean` | `exists` 返回是否存在匹配节点；`click`、`longClick` 返回是否至少成功操作一个匹配节点。 |

**详细说明：**

查询按选择器全部条件匹配查询范围内的节点树，范围由 [nodeLib.setWindowMode](节点库.md) 决定，默认只查当前活动窗口。无障碍服务未开启时，查询会直接报错，不会等待超时。

`exists` 只判断是否存在匹配节点，不创建节点对象，适合只做条件判断的场景。

`node:findOne`、`node:findAll` 只在该节点的子孙节点中查找，不包含节点自身；`depth` 条件仍按整棵树的层级计算。节点已失效时返回 `nil` 或空表，不会等待超时。

`selector:click`、`selector:longClick` 会对全部匹配节点执行无障碍动作。如果没有任何匹配节点接受该动作，就对第一个可见的匹配节点，在其可见区域中心执行一次手势点击或长按，详见[节点动作](节点动作.md)。

节点对象只适合在当前界面使用，界面变化后应重新查询。选择器动作不返回节点，适合不需要读取节点信息的直接点击和长按。

```lua
local list = id("android:id/list"):findOne(2000)
if list then
    local items = list:findAll(className("android.widget.TextView"))
    print("列表项数量", #items)
end

if text("同意"):exists(3000) then
    text("同意"):click()
end
```
