---
params: "无"
returns: "string、integer、boolean、node、node 数组或坐标"
---

**方法名称：** 读取无障碍节点的字段、状态、区域和父子关系。

**语法：**

```lua
node:id()
node:text()
node:desc()
node:className()
node:packageName()
node:childCount()
node:drawingOrder()
node:depth()
node:index()
node:visibleToUser()
node:selected()
node:clickable()
node:longClickable()
node:enabled()
node:password()
node:scrollable()
node:checked()
node:checkable()
node:focusable()
node:focused()
node:bounds()
node:boundsInParent()
node:childs()
node:parent()
node:refresh()
node:toJson()
```

**参数说明：** 无。

| 返回值 | 说明 |
|---|---|
| `string` | `id`、`text`、`desc`、`className`、`packageName` 或 `toJson` 的结果。 |
| `integer` | `childCount`、`drawingOrder`、`depth`、`index` 的结果。 |
| `boolean` | 状态方法的结果；`refresh` 返回是否成功读取到最新状态。 |
| `left, top, right, bottom` | `bounds`、`boundsInParent` 返回四个整数。 |
| node 数组 | `childs` 返回直接子节点。 |
| node 或 `nil` | `parent` 返回父节点；根节点没有父节点时返回 `nil`。 |

**详细说明：**

字段方法包括 `id`、`text`、`desc`、`className`、`packageName`、`childCount`、`drawingOrder`、`depth` 和 `index`。`index` 是节点在父节点中的序号，从 `0` 开始。`bounds` 是屏幕坐标，`boundsInParent` 是相对父节点的区域。

状态方法与同名选择器条件一一对应：`visibleToUser`、`selected`、`clickable`、`longClickable`、`enabled`、`password`、`scrollable`、`checked`、`checkable`、`focusable` 和 `focused`。

字段和状态都是查询时的快照。点击开关等操作后，需要先调用 `refresh` 从当前界面重新读取；节点已不存在时 `refresh` 返回 `false`，并保留原有字段。`toJson` 返回当前快照全部字段组成的 JSON 文本，不包含子节点。

节点来自短期句柄。应用界面刷新、无障碍服务断开或脚本结束后，旧节点可能失效：动作返回 `false`，`parent`、`toJson` 返回 `nil`，`childs` 返回空表，已读取的字段仍可使用。需要继续操作时，应重新执行选择器查询。

```lua
local switch = className("android.widget.Switch"):findOne(2000)
if switch then
    print("当前开关", switch:checked())
    switch:click()
    if switch:refresh() then
        print("点击后开关", switch:checked())
    end
end
```
