---
params: "path: string（仅 saveNode/saveNodeNew）；mode: string（仅 setWindowMode）"
returns: "string、boolean 或 nil"
---

**方法名称：** 控制无障碍服务、切换查询窗口、导出节点树和锁定节点树快照。

**语法：**

```lua
nodeLib.getNodeXml()
nodeLib.saveNode(path)
nodeLib.saveNodeNew(path)
nodeLib.lockNode()
nodeLib.unlockNode()
nodeLib.setWindowMode(mode)
nodeLib.openAccessibility()
nodeLib.closeAccessibility()
```

**参数说明：**

| 参数 | 类型 | 说明 |
|---|---|---|
| `path` | `string` | 保存节点 XML 的完整文件路径；父目录不存在时会尝试创建。 |
| `mode` | `string` | 查询窗口范围：`"active"` 只查当前活动窗口（默认），`"all"` 查询全部可交互窗口。 |

| 返回值 | 说明 |
|---|---|
| `string` 或 `nil` | `getNodeXml` 返回当前查询范围的 XML；当前没有节点树时返回 `nil`。 |
| `boolean` | 其他方法返回操作是否成功。 |

**详细说明：**

| 方法 | 说明 |
|---|---|
| `getNodeXml` | 将当前查询范围序列化为 XML；已锁定时导出锁定的快照。 |
| `saveNode` / `saveNodeNew` | 将 XML 覆盖写入指定路径；`saveNodeNew` 是同一实现的兼容别名。 |
| `lockNode` | 按当前窗口模式复制整棵节点树作为快照。再次调用会替换旧快照。 |
| `unlockNode` | 释放快照，后续查询重新读取当前界面。 |
| `setWindowMode` | 切换后续查询、锁定和导出使用的窗口范围；不影响已锁定的快照。 |
| `openAccessibility` | 服务已连接时返回 `true`；无法自动启用时打开系统无障碍设置并返回 `false`。 |
| `closeAccessibility` | 关闭本应用无障碍服务并返回是否成功。 |

`"all"` 模式按窗口层级从上到下查询，弹窗、悬浮窗、输入法和系统对话框中的节点优先匹配。系统没有返回窗口列表时，会退回当前活动窗口。窗口模式在脚本结束后恢复为 `"active"`。

锁定期间，选择器查询、`childs`、`parent` 和 XML 导出都使用快照，不受界面刷新和窗口切换影响，遍历时也不再逐个跨进程读取节点，适合在同一界面上连续查询多次。节点动作仍作用于实时界面中的对应控件。锁定的是节点树，不是屏幕图像；使用结束后应及时调用 `unlockNode()`，脚本结束时平台也会自动清理。

XML 节点属性包括 `index`、`text`、`resource-id`、`class`、`package`、`content-desc`、`checkable`、`checked`、`clickable`、`enabled`、`focusable`、`focused`、`scrollable`、`long-clickable`、`password`、`selected`、`visible-to-user`、`drawing-order` 和 `bounds`。`"all"` 模式下，各窗口的根节点统一放在 `<hierarchy>` 根元素中。文本中 XML 不允许出现的控制字符会被移除。

无障碍服务未开启时，`getNodeXml` 和 `saveNode` 会报错，`lockNode` 返回 `false`。

```lua
if nodeLib.openAccessibility() then
    nodeLib.setWindowMode("all")
    nodeLib.lockNode()
    local xml = nodeLib.getNodeXml()
    print(xml or "当前没有节点树")
    nodeLib.unlockNode()
end
```
