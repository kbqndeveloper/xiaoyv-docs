---
params: "text、row、column、startIndex、endIndex 或 position（按动作）"
returns: "boolean"
---

**方法名称：** 对查询到的无障碍节点执行动作。

**语法：**

```lua
node:scrollUp()
node:scrollDown()
node:scrollLeft()
node:scrollRight()
node:scrollForward()
node:scrollBackward()
node:click()
node:longClick()
node:focus()
node:clearFocus()
node:copy()
node:paste()
node:cut()
node:select()
node:collapse()
node:expand()
node:contextClick()
node:setText(text)
node:scrollTo(row, column)
node:setSelection(startIndex, endIndex)
node:setProgress(position)
```

**参数说明：**

| 参数 | 类型 | 说明 |
|---|---|---|
| `text` | 任意值 | `setText` 的文本内容；会转换为字符串，`nil` 转为空字符串。 |
| `row, column` | `integer` | `scrollTo` 的目标行和列；省略值按 `0`。 |
| `startIndex, endIndex` | `integer` | `setSelection` 的文本选择起止位置。 |
| `position` | `number` | `setProgress` 的目标进度。 |

| 返回值 | 说明 |
|---|---|
| `boolean` | Android 无障碍节点是否接受并成功执行该动作。 |

**详细说明：**

无参数动作包括 `scrollUp`、`scrollDown`、`scrollLeft`、`scrollRight`、`scrollForward`、`scrollBackward`、`click`、`longClick`、`focus`、`clearFocus`、`copy`、`paste`、`cut`、`select`、`collapse`、`expand` 和 `contextClick`。

带参数动作包括 `setText`、`scrollTo`、`setSelection` 和 `setProgress`。动作能否成功取决于目标节点是否支持对应的 Android 无障碍动作。

`click`、`longClick` 有手势后备：节点不接受无障碍点击时，如果节点对用户可见，就在节点位于屏幕内的可见区域中心执行一次无障碍手势点击或长按。手势不需要 Root。很多文字节点本身不可点击，真正响应点击的是外层容器，按中心坐标点击可以命中容器。节点不可见或完全位于屏幕外时不执行手势，返回 `false`。

其他动作返回 `false` 时，不会自动改用其他输入方式。

```lua
local input = className("android.widget.EditText"):findOne(2000)
if input then
    input:focus()
    assert(input:setText("小鱼精灵"))
    input:setSelection(0, 2)
end
```
